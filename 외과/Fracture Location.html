외과. 골절 위치 구분 — 골간 · 골간단 · 성장판 · 골단 (Diaphyseal / Metaphyseal / Physeal / Articular) ｜ 헷갈림 정리
한 줄 요약 — 관절 끝에서 뼈 가운데 쪽으로 골단(epiphysis) → 성장판(physis) → 골간단(metaphysis) → 골간(diaphysis) 순서로 붙어 있다. 골절 위치는 골절선이 이 중 어디를 지나느냐로 부른다.
용어 주의 — "physical"이 아니라 physeal(피지얼, physis의 형용사)이다. Diaphyseal · metaphyseal · epiphyseal 모두 같은 꼴(-physis → -physeal).
강의 근거: 「골절 역학」 PDF 30–31쪽(Fx location: Diaphyseal 근위·중간·원위 / Metaphyseal / Articular-condylar / Avulsion), 37–43쪽(Salter-Harris, physis 생체역학). 그 밖의 설명은 보충.
그림 1. 장골의 네 부위 — 관절 끝에서 안쪽으로 「골단 → 성장판 → 골간단 → 골간」 (원위 대퇴골 모양으로 단순화)
이름으로 외우기 (한자가 제일 쉬움) 보충
골간(骨幹) — 幹 = 나무 줄기. 뼈의 몸통.
골간단(骨幹端) — 幹端 = 줄기의 끝. 몸통이 끝나면서 넓어지는 곳.
골단(骨端) — 端 = 끝. 뼈의 맨 끝(관절).
성장판 — 골단과 골간단 사이에 낀 연골 판.
영어: dia(사이·관통 → 양 끝 사이 몸통) · meta(다음 → 성장판 바로 다음) · epi(위에 → 끝에 얹힌 모자) · physis(자라다 → 성장판)
X-ray에서 어떻게 구분하나 보충
골간: 양쪽 피질이 평행하고 두꺼운 흰 선, 가운데 골수강 → "관(tube)"
골간단: 뼈가 넓어지기 시작하는 깔때기 · 피질이 얇아지고 속이 그물 모양(해면골)
성장판: 골단과 골간단 사이 검은(방사선 투과) 띠 — 어린 개체에서 정상 구조이지 골절선이 아니다 → 헷갈리면 반대쪽 다리와 비교
골단: 성장판 바깥 둥근 머리 · 관절면(관절연골은 X-ray에 안 보임)

자주 헷갈리는 6가지

  1. 근위 골간 vs 골간단 — 경계는 "뼈가 넓어지기 시작하는 곳". 피질이 아직 평행하면 근위(원위) 1/3 골간, 벌어지고 속이 그물 모양이면 골간단. 애매하면 AO 사각형 규칙(그림 1): 관절 끝 최대 폭으로 정사각형을 그려 안에 들어가면 골간단·골단 쪽 분절 보충.
  2. 성숙 개체에는 physeal fx가 없다 — 성장판은 대개 생후 1년 전후에 닫힌다(뼈·견종마다 다름) 보충. 같은 자리라도 성견이면 metaphyseal 또는 condylar(articular) fx라고 부른다 필기.
  3. Salter-Harris "Ⅱ"의 골간단 조각 — 골절선이 성장판을 따라가다 골간단 쪽으로 꺾여 삼각형 조각(Thurston-Holland 골편)을 만든다. 골단 쪽으로 꺾이면 Ⅲ(관절 침범). Ⅱ = 골간단(meta) / Ⅲ = 골단(epi).
  4. Supracondylar vs Condylar — supra(위) = 과 위 = 관절 밖 = 골간단 골절 / condylar = 과 자체 = 관절 골절.
  5. 어린 개 X-ray의 검은 띠 — 정상 성장판. 골절로 읽지 말 것. 띠의 폭이 넓어졌거나 어긋나 있으면 SH Ⅰ을 의심 → 반대쪽과 비교.
  6. Epiphyseal = 거의 articular — 골단은 관절면을 덮고 있어 골단 골절은 대부분 관절면까지 들어간다. 그래서 SH Ⅲ·Ⅳ는 성장판 + 관절 둘 다 신경 써야 한다(정확한 정복 + 성장판 보호).
