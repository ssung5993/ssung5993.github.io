# 수의학 정리본 아카이브

사이트 주소: https://ssung5993.github.io

## 정리본 추가하는 법
1. 과목 폴더(외과, 소동물내과, 대동물내과, 산과, 인공수정학, 수생의학, 진단검사의학, 임상병리학, 방사선학)에 들어가요.
2. **Add file → Upload files**로 HTML 파일을 올리고 **Commit changes**를 눌러요.
3. 파일 이름이 사이트에 제목으로 표시돼요. 1~5분 뒤 새로고침하면 목록에 나와요.

소동물내과의 간단 정리본은 `소동물내과/간단 정리본/` 폴더에 넣으면 따로 모여요.

## 문제풀기
- 기출 문제(수의내과학 2023·2024·2025)는 `index.html` 안에 들어 있어요.
- Claude로 자동 생성해 저장해 둔 문제 세트는 `data/quizzes.json`에 있어요.
