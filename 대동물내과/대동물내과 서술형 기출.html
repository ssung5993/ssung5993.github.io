021위 산증 (Ruminal acidosis)서술형 출제예정
묶어놓은 문제

22년도 2번.1위 산증(Ruminal acidosis)에 대해 기술하시오.

관련 내용
정의
= 곡물과식증(식체), 1위 산성증. 발효하기 쉬운 곡물(고탄수화물성 사료)을 한번에 과량 섭취(분쇄된 곡물은 더 위험) → 1위 내 젖산(Lactic acid) 과량 생성 → 급성 질병
정상 1위 pH 6.0~7.0 (섬유소 분해균에 적합한 환경)
· 급성 1위 산증 ARA: pH < 5.0 · 아급성 1위 산증 SARA: pH < 5.5
기병론 (Cascade)
탄수화물↑ → Pyruvate → VFA↑ → Rumen pH↓ → Streptococcus bovis↑ → Lactate↑ → Rumen pH↓ → 세균 성장↓ → Rumen pH < 4.5 → Lactobacillus↑ → D-lactate↑ → 흡수 → Blood lactate↑ → 대사성 산증
동반 변화: VFA↑, 세균 내독소(endotoxin)↑, 1위 삼투압↑, 1위 상피 parakeratosis·농양 / 1위 세균이 혈류로 유입 → 전신 감염
Cascade 설명
  1. 발효하기 쉬운 탄수화물 과량 섭취 → 정상 미생물총이 VFA 다량 생성 → 1위 pH 감소
  2. Streptococcus bovis 증가 → 과량의 젖산 생성
  3. 산이 pH를 더 떨어뜨림 → 정상 미생물총 사멸 & Lactobacillus 급증
  4. Lactobacillus가 젖산을 더 생성 → pH 더 저하 → 악순환
  5. 낮아진 pH → 1위 운동 정지
임상증상
1위 운동정지, 심한 탈수증, 독혈증, 전신쇠약 & 횡와 → 높은 폐사율
  • 탈수증: 1위 내 과량의 젖산 → 1위 내 삼투압 증가 → 1위 내로 수분 유출·저류 → 탈수증 & 혈액농축
  • 제1위염: 과량 젖산이 위벽 자극 → 화학적 1위염 & 이상각화증 / 산에 저항하는 진균(Mucor, Rhizopus, Absidia) 증식 → 진균성 1위염(혈전증·경색) → 간으로 파급 → 간농양
  • 산증: 1위 내 젖산이 소장에서 혈액으로 흡수 → 대사성 산증
  • 배뇨량 감소: 탈수 → 신혈류·사구체 여과율 감소 → 무뇨증 → Shock → 폐사 (과식 후 24시간 이내 발생 가능)
임상상(Clinical picture): Rumen atony, Dehydration, Hydrorumen, Diarrhoea, Laminitis, Polioencephalomalacia, Parakeratosis-rumenitis-liver abscess complex, Pneumonia·Pyelonephritis·Endocarditis
연관 질환 — 젖산에 의해 pH 저하 → 세균 사멸·내독소 유출 → 체내 흡수 → 발굽의 알러지성 질환 = 제엽염 (사지에 발병, 제관부 열감 & 종창)
시험 답안
22-2

젖산 축적 → ① 1위 삼투압↑ → 탈수·혈액농축 → 무뇨·쇼크 ② 1위벽 자극 → 1위염·간농양 ③ 혈중 흡수 → 대사성 산증.

22년도 3번.단답비유량과 함께 식욕감퇴, 배변량 감소, 찐득한 연고모양의 증상을 나타내며 타청진 시 좌우늑골궁(9~12th 늑골 사이)에서 유향성 ping sound가 청취되는 질병명과 치료방법을 적으시오.

관련 내용
발생 — 분만 직후 or 수주 전후 다발 / 4위가 1위와 좌측 복벽 사이에 끼어 듦
유발요인 · 기병론
  1. 농후사료 과식: 과식된 농후사료가 신속히 4위로 → 다량의 VFA 생성 → 4위 운동 억제(무력증) → 섭취물·gas 증가 → 변위 / 상층에 gas 축적 → 좌측 복벽에서 ping sound
  2. 제1위의 거상: 임신 시 태아 무게로 1위가 복부 바닥에서 거상 → 4위가 그 간격으로 좌측 변위 → 분만 후 침하된 1위에 갇혀 4위 내용물 통과장애
  3. 비정상적 운동: 발정 시 jump·승가 같은 갑작스러운 운동 → 1위 거상 → 4위 좌측 변위
  4. 산·염기 불균형: 겨울철 알칼리 상태 → 4위 무력증 → 통과장애
주요 임상증상

  2. 좌측 복벽 소견: 좌측 겸부 전하방, 늑골궁 바로 뒤쪽 뚜렷한 팽대부 / 9~12번 갈비뼈 사이 늑골궁 청진 시 ping sound (경계선을 그리면 큰 난원형)
  3. 경과: 아급성·만성, 폐사하지 않지만 비유량 · 체중 감소
신체검사법 · 진단

  4. 혈액검사: 저클로르혈증·저칼륨혈증 동반 mild 대사성 알칼리증, 저칼슘혈증, 혈액농축 (특이적이진 않음)
감별진단 (족보에 "혹시 몰라서" 넣은 부분)

관련 내용
① 중독성 간염 (Toxic hepatitis)
원인: 독성 식물, Fungal toxin, Algae / 무기물: 인, 비소, Selenium / 유기물: Cresol, Chloroform, Gossypol

원인: 울혈성 심부전 → 간 중심정맥 압력 증가 → 중심소엽성 변성 → 무산소증 & 주위 간실질 압박
⑥ 선천성 간 부전 (Inherited hepatitis)

※ ⑥ 선천성 간 부전은 강의 PDF에 분류명만 있고 세부 설명 슬라이드는 없어요.

관련 내용

장내 암모니아 감소 약제 (25-4 답)
  • Neomycin — 장내 세균 억제
  • Metronidazole — 혐기성 세균 감소
  • Lactulose — 대장 내 pH 감소 → 암모니아를 암모늄 이온으로 전환 → 흡수 억제
관리법 (식이 관리)

  2. 적절한 탄수화물 함량 — 간에서의 포도당 합성 요구량 감소
  3. 지용성 비타민 보충
  4. 과도하지 않은 고품질 단백질 제공 (과도한 지방은 지방간 유발 가능)
