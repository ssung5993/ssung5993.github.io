7-1. 분만 Parturition

객관식·단답형 대비 압축본 — 분만 준비 · 분만 전 징후 · 분만 개시(호르몬·산도·태위) · 분만 경과(1·2·3기)
오른쪽 아래 빈칸 모드 버튼 → 그림 라벨·번호표가 가려짐, 칸을 누르면 정답

0. 개요I. 분만 준비II. 분만 전 징후 III-1. 호르몬III-2. 산도III-3·4. 태위·태향·태세 III-5. 만출력IV. 분만 경과총정리

0 분만 개요

  • 분만(parturition): 태아가 태반과 같이 모체 밖으로 배출되는 현상
  • 정상분만: 정상 임신기간 경과 후 만출력에 의해 태아가 산도를 통해 자궁으로부터 만출
분만기시작 ~ 끝
제1기 (개구기)간헐적 진통 발작으로 시작 → 태포의 질 내 진입과 파수
제2기 (출산기)진통 반복, 노책 동반 복압 증가 → 태아 만출
제3기 (후산기)태아 만출 직후 ~ 태막이 완전히 배출될 때까지
  • 분만개시 기전: progesterone ↓, oxytocin에 대한 자궁근 감수성 ↑, estrogen·relaxin에 의한 골반인대 이완, 태아 발육에 따른 자궁·경관 자극

I 분만 준비

  • 분만 전 모체: 충분한 영양과 물 (적절한 배합사료)
  • 돼지: 분만 시·분만 후 48~72시간 자돈 폐사(주로 압사) 20~30% / 최적 환경온도 29~35℃
  • 개: 출산 장소·상자에서 한 달 정도 순치
  • 분만은 생애 중 가장 위험하고 폐사율 높은 시기
  • 준비물: 소독약·탈지면·가위·실·윤활제(비누, 올리브유) / 야간 전등 / 깨끗한 온수 / 초산우 — 견인 도구 / 건초·볏짚, 보온기구 / 소독 거즈·수건·항생물질

II 분만 전의 징후 — 분만 시기 특정은 어려움

1. 골반인대의 이완

  • 소: 천좌인대(sacrosciatic ligament) 점차 이완 → 둔부 인대·근육 함몰
  • 태반·부신의 estrogen ↑, relaxin ↑ → 교원섬유 변화·부종 → 천좌인대·자궁경관·회음부 이완
  • 젖소 인대의 극도 이완 → 24~48시간 후 분만
  • 말: 엉덩이 두터운 근육 때문에 현저하지 않음

4. 기타 참고사항

  • 번식기록 중요 — 소 분만예정일: 수정월 −3(+9), 수정일 +6~11
  • 개 초음파 분만일 예측
    • 임신 37일 이전(뼈 형성 전): 융모막강 안쪽 직경(inner chorionic cavity diameter)
    • 임신 38일 이후(뼈 형성 후): 태아 머리부분 직경(head diameter)
    • 견종별 공식(진돗개·말티스·요크셔테리어·시츄·미니어처슈나우저) / 원형이 아니면 긴 지름·짧은 지름 평균, 2마리 이상이면 평균치

III-1 분만의 개시 — 임신 말기 혈중 호르몬

  • 배반포(임신 1~2주)가 자궁내막에 작용 → 황체퇴행인자(PGF2α) 분비 억제
  • 황체 P4 → 자궁근·자궁내막 작용 → 임신 유지 / 자궁유(uterine milk) 분비: 임신 초기 1/3
  • P4가 FSH 생산 억제 → 난포 발달·발정 억제 → 임신기간 황체 유지
  • 말: 임신 40~120일 부황체 형성
  • 분만 전 융모막요막·부신의 P4로 유지되는 시점: 말 150~200일~, 양 55일~, 개 30일~, 고양이 50일~

임신 후반기

  • 소 임신 후기: estrogen 2~3.5배 ↑, 혈장 progesterone ↓
  • Estrogen: 태반 분비 ↑ → oxytocin에 대한 자궁근 감수성 ↑
  • Relaxin: 소·돼지, 임신 후기 골반조직·경관 이완
  • Oxytocin 주사로 분만 유도 가능: 사람, 말, 돼지
  • 태반 노화 → P4 분비 ↓ → 분만
  • 태아 corticoid ↑ → estrogen ↑, PGF2α ↑ → 황체 퇴행

III-2 출산길 (산도)

  • 태아와 부속물이 통과하는 경로: 골반, 자궁경관, 질, 외음부

골반강 (원추형)

  • 골반입구: 복강과 접하는 큰 구멍, 골반강의 가장 넓은 부위, 소는 확장성 적고 말은 큼
    • 최대직경: 천골~치골 사이 / 형태: 소·돼지 = 타원형(장원형), 말·개 = 원형
    • 대동물 태아의 흉부·둔부 횡단면은 골반입구보다 크지만, 분만 시 위치변환·정복으로 출산 가능
  • 골반출구: 골반입구보다 좁다 / 등쪽 = 미추, 옆면 = 천좌인대 뒷가장자리, 뒷면 = 좌골궁(ischial arch)
    • 골반 전부보다 확장성이 큼(천좌인대 이완) — 소에서는 이 부위 이완이 분만 임박의 명백한 지표
  • 골반축(골반유도선): 골반입구·골반강·골반출구 중심점을 잇는 가상선 = 태아 종축이 통과하는 중앙선

2) 연부출산길 (Soft birth canal)

  • 뼈출산길보다 확장성 풍부
  • 자궁목관과 외음부는 질보다 확장성이 적어 분만 시 간혹 손상
  • 자궁목관 확장은 주로 태아 선진부와 양수(태포)의 진행에 의해
  • 자궁목관 확장: 말 > 반추동물·돼지, 경산 > 초산 (용이)

분만 시 태아의 위치

  • 두위: 임신 중 하태향(말, 단태동물)이던 태아가 자궁수축으로 회전 → 상태향, 코·앞다리를 외음부쪽으로
  • 미위: 소의 미위 분만 시 질식사 위험
  • 소: 두위 95%, 1위(반추위) 압박으로 25~30° 우태향에 가깝게
  • 말: 99% 두위상태향
  • 돼지·개: 30~40% 미위, 태위·태향 불규칙, 두위·미위 엇갈림, 자궁목관 가까운 태아부터 순차 출산

III-5 만출력 · 진통

  • 만출력: 분만 시 태아·부속물을 만출시키는 자궁의 힘
  • 진통(labor pains): oxytocin과 estrogen의 작용으로 분만 시 불수의적·주기적으로 반복되는 자궁근 수축, 동통 수반
  • 단태동물: 자궁뿔 앞부분부터 후방으로 파급 / 다태동물: 자궁목관에 가까운 태아부터, 나머지는 정지
  • 진통발작: 진행기(증진기) → 극기 → 퇴행기 / 간헐기: 진통 휴지기, 극기에서 태아 혈액순환장애 방지에 중요
  • 시간·강도: 분만 초기 10~15분마다 15~30초 약한 진통 → 진행 시 3~4분마다 1분 → 만출기: 가장 강하고 길며 진통 시간이 간헐기보다 김 → 분만 후: 짧아지고 간헐기 길어짐 → 후산진통
  • 진통발작 원인: oxytocin, 태아 말단부의 자궁목부분 신경절 압박·자극

IV 분만의 경과

1. 성숙태아와 골반경

  • 머리·가슴·허리가 산도 통과 곤란 → 머리+앞다리 지름을 줄이려면 앞다리 신장 필요
  • 가슴 지름 > 모체 골반강: 수축성 있음 → 앞다리를 당기고 늑골·견갑골을 경사 상태로
  • 허리 < 모체 골반지름: 수축성 없음 → 태아 요부를 45~90° 회전 시 만출 용이

2. 분만 제1기 (개구기)

  • 규칙적 개구진통으로 자궁목관이 완전히 확장되어 질과 경계 없이 이행될 때까지
  • 소 자궁근 수축: P4 저하, 고농도 estrogen / 태막·태수를 이완된 목관 쪽으로 압출
  • 소 목관 개장: 자궁종주근 수축 → 경관외구 직경 8~12 cm 도달 후 2~4시간 뒤 경관내구 열림 → 6~12시간까지 목관·질이 15~18 cm 폭 연속 도관
  • 소 자궁수축: 10~15분마다 15~30초 → 3~5분마다 강한 수축
  • 말·개: 제1기에 태아가 하태향·측태향 → 상태향으로 회전
  • 다태동물: 목관 근접 태아 부근에서만 수축, 한 마리 만출 후 다음 태아 부근에서 반복
  • 제1기 길이: 다경산 < 초산
  • 개: 제1기 중 또는 직전 체온 0.5~1℃ 급저하(37.7℃, P4 저하 관련), 때때로 구토
  • 제1파수: 제1기 후반, 요막융모막(태포)이 질강 내로 밀리며 파열 / 태포 = 암적색 / 이후 양막이 목관 내로 / 돼지는 파수 양이 적어 잘 관찰 안 됨

3. 분만 제2기 (산출기)

  • 개장된 산도로 태아 진입, 양막낭(황백색·반투명) 파열, 복부 수축, 진통, 태아 만출
  • 양막 내 태아 머리·발굽 투시 = 족포(foot sac)
  • 소 자궁수축: 10분마다 4~8회, 80~100초 지속
  • 제2파수(양막낭 파열): 발굽이 음문을 통과할 때 / 양수는 점조, 태변 혼입으로 때로 갈색(제1파수와 구별)
  • 태아 머리가 음문 통과 시 최강의 복부 노책 / 조기 파수: 제1파수가 자궁목관 내에서 일어날 수 있음
  • 소·말에서 제2기 6시간 이상 → 태위 이상, 자궁염전, 자궁무력증 암시
  • 혈중 oxytocin 지속 현저 증가 (반감기 1~1.5분)
  • 거의 모든 동물은 노책 시작 시 횡와, 말·소는 때로 기립

4. 분만 제3기 (후산기)

  • 태막 배출 및 자궁 퇴축
  • 태아 출생 → 태아 태반 맥관 붕괴, 융모 위축
  • 태아 만출 후 자궁은 48시간 강력 수축 → 이후 강도 줄여 자주 수축 → 출혈 방지·태막 배출 촉진
  • 융모 위축 → 태아 영양막과 모체 자궁소구 상피 분리 (일부 융모 잔류 가능)
  • 중자궁동맥 수축: 특징적 진동 소실
  • 포유 → 뇌하수체에서 oxytocin 방출 → 태막 배출 촉진
  • 개·고양이: 태아와 태아 사이 불규칙 배출 / 돼지: 분만 중 2~3두마다, 최후 태아 후 20분~12시간(평균 4시간)
  • 태막 배출 후 점조한 점액 → 자궁목관을 막아 감염 방지
