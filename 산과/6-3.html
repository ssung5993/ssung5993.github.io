III 자궁외임신

1. 진성 자궁외임신

  • 수정란·태아가 자궁 이외의 기관·조직에서 어느 정도 발육 — 가축에서는 현재까지 미관찰
  • 사람: 난소, 난관(일반적, tubal pregnancy), 복강에 착상 · 1~2% · 태아는 단기간 발육 후 사멸 · 난관 파열 → 심한 출혈

2. 가성(속발성) 자궁외임신

  • 정의: 자궁내막과 정상 태반 관계를 형성해 발육하다가 자궁강에서 복강(자궁파열)이나 질로 탈출
  • 발생 시기: 보통 임신 2/3 시기 이후 · 진단 시점에 보통 태아는 죽어 있음
  • 관찰: 자궁꼬임, 기종태, 만성 자궁외막염 / 개: 난산 및 oxytocin 투여 후
  • 부작용: 탈출태아가 복강장기와 광범위한 유착
  • 진단: 대가축 — 도살 시 발견, 그 전 발견 시 도태, 개복술 비권장(대부분 유착 남김) / 개·고양이 — 복부 촉진, X-ray, 탐색적 개복술
  • 임신 말기·분만 시 자궁 손상, 꼬임, 기종태 → 자궁파열 속발 / 기종태·심한 감염 → 모체 복막염, 쇼크

IV-1 태막 및 태아의 수종

  • 종류: 양막수종(hydramnios), 요막수종(hydrallantois), 융모막요막수종 / 태아 전신수종, 복수증, 흉수증 동반 태아수종
  • 소 쌍태의 경우 수종성 질환 가능성 검사 필수
  • 양막수종·요막수종이 가장 일반적 — 요막수종 발생률이 높음

1) 양막수종 (Hydramnios)

  • 양막강의 점진적 증대·팽만, 유전성·선천성 이상 태아 동반 · 소에서 다발, 말은 보고 없음
  • 정상 양수: 태아 보호, 매일 일정량 증가, 연하에 의해 태아 소화기계로 전달
    • 소: 초기~중기 물같이 투명·약간 황색 → 중기 점도 증가(타액 혼합), 양 2배, 분만 월까지 서서히 증가
    • 양: 임신 100일 전후 양수 급격히 증가
  • 양막수종 태아: 연하 방해 → 양수 서서히 증가
  • 양수량: 정상 임신 말기 소 4~8 L / 양막수종 20~120 L
  • 분명해지는 시기: 임신 말기 2~3개월
  • 원인 질병(이상 태아)
    • ① 불도그 송아지 임신한 덱스터 품종 — 임신 3~4개월부터 수종 명백
    • ② 골수강 결핍·왜소·짧은아래턱증 태아 임신한 앵거스 — 임신 마지막 달 복부팽만
    • ③ 뇌하수체 형성부전·무형성 동반 미숙왜소 ④ 뇌수종 ⑤ 중복쌍태 기형 ⑥ 반전성열체 ⑦ 각종 머리부분 기형
  • 대부분 태아측 원인 → 모축의 번식예후는 보통 또는 양호
  • 장기임신 + 뇌하수체 결함 태아 동반 시 호르몬 처치: PGF2α + glucocorticoids + estrogen 병용 / 제왕절개 고려

2) 요막수종 (Hydrallantois)

  • 소의 태아·태막 수종성 질환 중 85~90%
  • 특징: 자궁의 질환을 동반
    • 한쪽 자궁뿔의 자궁소구 거의 모두 기능 상실 / 태반 확대·병적(괴사성·부종성)
    • 부태반(adventitious placenta) 보통 관찰 / 본태반은 괴사·부종 / 쌍태임신 소에서 다발
  • 원인: 혈관 이상 / 요막융모막의 구조적·기능적 변화 / 태아 콩팥 이상(cystic kidney, hydronephrosis, polyuria) / 사료 작물 — 비타민 A 저하 시기(자궁속막 항병성 저하)
  • 증상
    • 자궁소구 결여, 자궁 현저히 팽대·이완·무력증(유산·난산) / 태아는 작고 경도 부종·복수, 출산 시 이미 폐사 또는 직후 폐사
    • 속발증: 태반정체, 패혈성 자궁염 / 태막: 두텁고 무거운 부종성(파열은 안 됨)
    • 뻣뻣하고 완만한 걸음 → 기립불능 / 흉골을 바닥에 대고 엎드림 → 개구리 같은 자세
    • 치골전건 단열, 복벽 허니아, 자궁파열

3) 요막융모막 수종 / 4) 태아복수증 / 5) 수종태

  • 요막융모막 수종: 조직이 10~15 cm 두께로 확대 · 원인 Brucella abortus 감염
  • 태아복수증: 경도 태아복수증 및 수종 / 태아가 자궁 내 폐사 후 무균적 자가융해 시
  • 수종태: 태아전신부종(fetal anasarca), 태아수종(hydrops fetalis) · 소(보편적), 양(간헐적) · 원인: 경도 양막수종·요막수종 또는 합병

6) 수종의 예후

  • 양막수종: 일반적으로 어미 예후 양호 (단, 기립불능 시 매우 불량)
  • 요막수종: 비교적 불량 — 자궁 이완·태막 장애, 만출·적출 후 쇼크·패혈성 자궁염, 어미 폐사율 높음, 생존해도 번식능력 저하
  • 요막융모막 수종: 예후 불량 / 거의 모든 수종 태아는 자궁 내나 출산 직후 사망
  • 이상 태향·태세의 수종성 사태아, 무력자궁, 자궁경관 확장부전 → 난산 / 심한 태아복수증·수종태 → 유산, 과대 태아로 인한 난산

7) 치료 · 처치

  • 경미한 예(유산·조산·정상 분만 때까지 미진단): 대량 태수, 소형 이상 태아 → 난산, 자궁무력증 / 태아 정복·견인 추출 용이
  • 태아복수증·수종태: 강력한 견인, 대량 윤활제, 절태술(간혹)
  • 요막·요막융모막 수종 후 태반정체·극심한 자궁염: 비경구·국소 항생물질 + 자궁수축제(ecbolics) — oxytocin, 합성 estrogen, ergonovine
  • 유산 유도: 합성 estrogen·estradiol 대량 연일 / estrogen 단독 / 고용량 PGF2α / glucocorticoids + 항생물질 병용 → 자궁경관 확장 → 유산
    • Oxytocin 효과는 제한적 — 자궁벽이 이미 이완·확장된 상태
  • 제왕절개: 24시간 전 투관침으로 태수를 서서히 제거 후 시도 / 급속 시행 시 쇼크 / 전해질 불균형·탈수 → 수액
  • 패혈성 자궁염: 항생제 / 치료 어려우면 도축 권고

IV-2 태아의 폐사와 사후 변화

1) 태아 미라변성 (Fetal mummification)

  • 진행: 임신 중기~마지막 1/3 시기 태아 폐사, 임신황체 존재 → 7~10일 이내 유산 안 됨 → 수개월 내 융해·침지 없음 → 자가융해, 태반 수분·태수 흡수, 모체 태반 퇴축 → 미라변성
  • 생존 태아 + 폐사 태아 함께 정체: 돼지, 개 / 영구황체 동반 미라변성: 소, 산양, 돼지, 개
  • 종류: 소 = 출혈성형(hematic type) — 자궁내막·태막 사이 출혈, 점조한 적갈색 응괴 / 돼지 등 = 종이모양 변성형(papyraceous type) — 태아 갈색, 태반출혈 없음

① 소

  • 건지종·저지종에서 가장 많음 · 발생 임신 3~8개월(4~6개월) (초기엔 골형성 부족으로 흡수, 후기엔 미라화 전 분만 → 사산)
  • 원인: 유전(건지·저지) / 제대꼬임, 태아 말단 주위 엉킨 탯줄 압박 / 감염 — Campylobacter fetus, 렙토스피라, BVD-MD / progesterone 또는 유사물질
  • 증상: 자궁벽 수축(태아·태막 밀착) / 태아 조직 건조 → 굳은 가죽 / 직장검사 시 정상보다 작은 자궁, 자궁벽 비후, 태반 촉진 안 됨 / 자궁동맥 가늘고 진전(fremitus) 촉지 불가 / 황체 존속 동반 발정 정지
  • 발생률 낮고 산발적
  • 치료: Stilbestrol 50~80 mg 또는 estradiol 5~8 mg 근육주사 / 존속 임신황체 제거 → 발정, 내용물 배출 / PGF2α 25~50 mg, cloprostenol 500 μg / 좌·우 허구리 제왕절개

② 말 · ③ 양 · ④ 돼지 · ⑤ 개·고양이

  • 말: 드묾 — 태반면적 부족으로 폐사된 쌍태 중 한쪽 미라변성 보고
  • 양: 태아사·유산 일으키는 감염증에 병발
  • 돼지: 임신 40~90일 폐사 태아 → 미라변성 → 분만 시 정상 태아와 같이 만출
    • 관련: Aujeszky, B형 일본뇌염, HVJ(구 Sendai), 돼지 cholera, SMEDI, Parvovirus, PRRS, Cytomegalovirus, Swine influenza, 렙토스피라
  • 개·고양이: 드묾, 산발적, 분만 시 정상 태아와 함께 1~3두 미라태아 만출
    • 석아(lithopedion, stone baby): 미라태아 체표에 석회 침착 → 돌처럼 경화
    • 석포(lithokelyphos): lithopedion의 한 종류, 태막 표면에 석회 침착

2) 태아침지 및 기종태

  • 임신 어느 시기에도 발생, 보통 임신 중기~분만기 · 소에서 가장 많음: 트리코모나스병, 캠필로박터병
  • 태아침지(maceration): 골이 잘 발육된 3개월 이후 (창상 감염균) / 소 — 중기 이후~분만기 (초기 흡수, 말기 사산) / 유산·난산
  • 기종태(emphysema): 태아사 후 부패균 오염 → 피하·내장 가스 축적 → 산도 통과 곤란 / 피하염발음(crepitus), 팽만 태아로 진단 / 개·고양이 — 복부 촉진, X선
  • 증상
    • 임신 중 패혈성 자궁염은 분만 후 패혈성 자궁염보다 위험·치명적
    • 자궁목 확장, 미진통, 태향·태세 이상, 태아 미배출 / 외음부 만성 악취·점액농성 배출물
    • 소·말 직장검사: 태아의 골이 자궁 내 농에 부유 / 자궁벽 두껍고 무거움, 자궁목 크고 견고 / 자궁내막 심한 퇴행·경화
    • 드물게 자궁외막염 → 자궁파열 → 침지태아가 복강 속 존재
  • 치료: 소 — 중기(태아 작음)면 자궁목 확장 확인 후 점활제로 견인 추출, 예후 나쁨 → 대부분 도축 권고 / 자궁목 비확장 — 항생제·설폰아미드, 합성 estrogen·estradiol / 말 — 손으로 자궁목 확장 후 추출 / supportive treatment / 제왕절개(다태동물: 자궁적출술)

V-1·2 복부 허니아 · 치골전건 단열

1. 복부(배부분) 허니아

  • 임신 자궁이 배꼽·서혜·회음·횡격막·복부 허니아 부위로 함몰 또는 그 속에 위치 / 치골전건 단열
  • 배꼽허니아: 유전성, 홀스타인
  • 서혜허니아: 선천성·후천성, 주로 개, 주로 편측성, 서혜부 부종, 난산 초래
  • 횡격막허니아: 보통 개의 외상
  • 회음허니아: 산양, 개
  • 배벽허니아: 작은 것 — 외상성 / 큰 것 — 자궁각이 허니아에 위치해 태아 일부 발육
  • 개의 허니아(임신 자궁 일부 함몰): 임신 초기 — 외과적 정복, 합성 mesh 수복 / 중기 — 자궁 절개·태아 제거 후 허니아륜 봉합
  • 광범위 편측성 복벽허니아: 소·양·산양 임신 후기 / 원인 — 외상, 임신 자궁·태아 중량 증가 / 복저부가 정상 대비 10~15 cm 처짐

2. 임신 중 치골전건(두덩뼈앞힘줄, prepubic tendon) 단열

  • 말에서 가장 흔함 — 소는 말에 없는 치골하건(subpubic tendon)이 보조 지지 → 드묾
  • 발생: 임신 마지막 2개월
  • 증상: 복저부 심한 부종, 유방~검상연골부(xiphoid)까지 동통성 부종 / 사진: sawhorse stance, 골반 기울어짐, 꼬리뿌리 올라감, 유방 부종
  • 원인: 임신자궁 중량 증가·부종에 의한 복저부 퇴행변성 / 외력·외상 / 쌍태, 태막수종, 양의 박새(veratrum) 중독
  • 돌발적 단열: 하복부 급격 팽대, 허구리 처짐, 발한, 호흡 촉박, 빠르고 약한 맥, 산통, 쇼크·출혈로 허탈
  • 예후: 항상 불량 (어미·태아 거의 분만 전 폐사)
  • 분만 전 치료: 대부분 효과 없음 / 말 — 임신 말기 oxytocin 또는 손으로 자궁목관 확장, 제왕절개 / 소 — 태아 견인으로 신속 만출

V-3 자궁꼬임 (Torsion of the uterus)

  • 정의: 자궁의 장축에 따른 회전·꼬임 / 소·양·산양: 활모양, U자형
  • 젖소에서 가장 많이 발생
  • 원인
    • 임신 후기 자궁각 대만부가 복저부에 자유롭게 위치 + 제1위·내장·배벽 지지 + 임각과 불임각의 비대칭 → 기립 시 돌발적 미끄러짐·넘어짐
    • 쌍태에서는 발생 가능성 낮음
    • 개·고양이: 태수 부족, 돌발적 전도·회전 / 장기간 축사 사육 / 자궁벽·자궁광간막 이완 → 장력 부족 / 태아의 활발한 운동
  • 발생시기: 보통 임신 후기, 소 — 임신 70일부터 만기
꼬임 정도양상예후
45~90°분만 전·분만 시 자연 회복, 증상 없을 때 있음90° 이하 — 치료 필요 없음, 양호
90~180°분만 시 확인 / 180° 이상 — 식욕부진·변비·반추정지·복통, 양은 목마 자세180~270° — 조기 치료 시 어미·새끼 모두 양호, 분만 전 재발 가능
방치 — 모체 불량, 태아 폐사
180~360°완전 산도 폐쇄 → 자궁혈액 공급장애(충혈·부종·쇼크·태아 죽음) / 임신 후기 심한 꼬임 — 식욕절폐·설사·호흡촉박·사지냉감·허탈, 24~72시간 내 폐사
  • 꼬임 부위: 소·말·양 — 질의 전방 부근 / 다태동물 — 자궁각간인대(intercornual ligament)가 없어 한 자궁뿔 전체 또는 일부 꼬임
  • 꼬임 방향: 단태동물 — 우방염전 < 좌방염전 (강의자료 표기 그대로)
  • 우방염전: 오른쪽 광간막이 아래로 강하게 견인되어 꼬인 자궁체·질 아래 위치 / 왼쪽 광간막은 자궁목 앞·자궁체·질 윗부분을 옆으로 감고 오른쪽으로 견인
  • 좌방염전: 오른쪽 광간막이 꼬인 산도 앞부분 위쪽을 강하게 감음
  • 진단: 양쪽 중자궁동맥 긴장 / 태아 하태향 = 꼬임 180° / 질 주름 — 좌방: 시계 반대 방향, 우방: 시계 방향(오른쪽 아래) / 외음부 등쪽 가장자리 견인 방향 / 심한 꼬임 — 비대칭 음순, 반대쪽 음순이 부음
  • 치료(분만 전 180~270°): ① 어미 소를 회전시키는 Schaffer's method ② 개복수술 — 손으로 정복 / (분만 시) 손으로 태아를 흔들어 정복(manual correction)

V-4 질탈

  • 정의: 질의 저부·측벽·상벽 일부가 음문을 통해 탈출 (자궁·자궁목도 후방 이동)
  • 품종: 소 — 헤리퍼드, 홀스타인, 브라운스위스 / 개 — 단두종(발정 시)

원인

  • Estrogen: 소에서 분만 2~3개월 전 태반에서 분비되는 대량 estrogen
  • 골반인대·주변조직·음문·괄약근 부종·이완 / 생식기 무력증, 전신 쇠약
  • 경산우(산도 손상·확장) / 고령우(강제 견인 난산 구조 경험) / 양 — 무성한 목초지에 갇혀 지내거나 쌍태 임신
  • 복부 과도 팽만, 골반 지방 침착 과다 → 골반강 내압 증가 / 유전적
  • 사료: 곰팡이 옥수수·대맥(estrogenic mycotoxin), subterranean clover(고농도 estrogen)
  • 개의 질탈: 비대된 질 점막이 팽만되어 탈출 / 복서, 대형 품종 / 발정전기와 발정기 / 유전적 estrogen 과다 / 이후급증(tenesmus), 교미 종료 전 무리한 분리
  • 양 (subterranean clover 등 콩과 식물): 자궁속막 낭포성 변성 → 장기 불임 / 유선 발육·부종 / 거세 수양의 요도구샘 비대 / 임신 양 — 자궁무력증·난산, 비임신 양 — 질탈

증상 · 예후

  • 노출 점막 부종·염증·동통·감염·괴사 / 횡와 시 음순 사이로 밀려 나옴, 경도는 기립 시 원위치
  • 약간 탈출 — 방광 포함 / 심한 탈출 — 팽만 방광, 괴사성 질탈, 지속 뒤무직 → 직장탈
  • 음문염·질염·자궁경관염, 노책·뒤무직, 패혈증·독혈증 → 폐사
  • 예후: 신속 처치 필요 / 재발 경향, 유전성 → 이유 후 환우 도태 고려

V-5·6 임신기의 마비 · 우발적 사고

5. 임신기에서의 마비

  • 원인 다양, 임신 후기에 발생해 임신 진행에 따라 악화
  • 1) 영양결핍·기아: 인·칼슘 결여 — 쇠약, 이식증, 뼈·관절 병변, 골절 / 구리·코발트·철 결핍 — 빈혈·쇠약, 극심 시 기립불능 / 심한 저영양 — 악액질(cachexia), 폐사, 유산
  • 2) 케톤증: 탄수화물 결핍 양의 임신병 — 임신 후기 기립불능·쇠약
    • 치료: 포도당 정맥주사, 프로필렌글리콜·글리세롤 경구, 소량 glucocorticoids 비경구
    • 예방: 탄수화물 섭취 증가(곡물·당밀), 운동량에 따라 급여량 조절
  • 3) 그라스 테타니: 밀 목초지 등 청초 목초지 방목 임신우, 가을·이른 봄 / 저칼슘혈증·저마그네슘혈증 또는 합병 / 예방 — 광물질, Ca·P 풍부한 알팔파·클로버 건초 / 치료 — 칼슘제 단독 또는 칼슘+마그네슘
  • 4) 분만전 유열: 유량 많은 소, 분만 직전·분만 제1기, 낮은 혈중 칼슘
  • 5) 산후급간(eclampsia): 개·고양이, 분만 후 2주 이내(분만 전), 저칼슘혈증, 신경질·불안·사지 강직·경련
  • 6) 태막수종·수종태: 임신 5개월 이후, 복부 중량 증가, 고관절 탈구, 기립 곤란
  • 7) 관절·건 손상: 후지 관절·건 손상 → 기립불능, 소 — 고관절 탈구
  • 8) 후지·척추 골절: 임신 말기 대퇴골·골반 골절 / 원인 — 다른 소의 승가행위, 장기 무기질 결핍, estrogen에 의한 관절·인대 과도 이완
  • 9) 패혈증·감염증: 태아 폐사·침지 동반 패혈성 자궁염, 기종태 속발 복막염 동반 자궁파열, 복막염 동반 극심한 자궁꼬임
  • 10) 기타: 자궁 대혈관 파열, 식중독, 광견병·리스테리아병(CNS), 요네병, 개선충, 노쇠, 림프세포종, 탄저·기종저·파스튜렐라·아나플라스마·렙토스피라 등 패혈성 질환, 발굽질환

6. 임신기의 우발적 사고

  • 임신 동물의 출혈: 소 태아의 출혈성 미라변성에서 관찰 / 소·말 — 창상·외력에 의한 대혈관 파열 / 신선혈 포함 적갈색 삼출액 음문 배출 — 유산 시초(태아사) 또는 패혈성 자궁염으로 자궁목 열림 / 렙토스피라병
  • 임신자궁의 파열: 임신 후기 원인 불명 우발적 / 유산·난산·기종태·자궁 유착 동반 만성 복막염·자궁꼬임·태막·태아 수종·외력·창상에 속발

  • 양막수종은 태아측 원인(유전·기형) / 요막수종은 자궁 질환 동반(부태반, 궁부 감소)
  • 요막수종 태막은 두껍지만 파열은 안 됨 / 수종 유산 유도 시 oxytocin 효과 제한적
  • 요막융모막 수종 원인 = Brucella abortus
  • 미라변성 종류: 소 = 출혈성형(적갈색) ↔ 돼지 = 종이모양형(갈색, 태반출혈 없음)
  • 석아 = 태아 체표 석회 / 석포 = 태막 표면 석회
  • 소 미라변성: 자궁 작게 촉진, 태반 촉진 안 됨, 중자궁동맥 진전 없음, 황체 존속 → 발정 정지
  • 임신 중 패혈성 자궁염(침지) > 분만 후 패혈성 자궁염 (더 위험)
  • 치골전건 단열 = 말(소는 치골하건으로 보조) · 예후 항상 불량
  • 자궁꼬임: 젖소 최다, 쌍태에선 낮음 / 다태동물은 자궁각간인대가 없어 자궁뿔 단위 꼬임 / 하태향 = 180°
  • 질 주름: 좌방 = 시계 반대, 우방 = 시계 방향 / 심한 꼬임 시 반대쪽 음순이 부음
  • 질탈 원인 호르몬 = estrogen / 치료 호르몬 = progesterone(임신 후기엔 분만 지연)
  • Bühner법 = 쌈지봉합, 분만 전·후 모두 / 음문폐쇄법 = Caslick 변형
  • 그라스 테타니 = 저Ca·저Mg, 청초 목초지, 가을·이른 봄 / 산후급간 = 개·고양이 저Ca / 임신병(케톤증) = 양
