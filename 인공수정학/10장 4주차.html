10-4. 병리학적 원인에 의한 불임증

출처 표시 — 수업 녹음 내용 · 필기 교본 위 손필기 · 보충 수의번식학 자료로 채운 내용 · 체크 시험 포인트 · 기출 25-7 2021~2025 중간고사 기출 (25-7 = 2025년 7번) · 태그 없음 = 교본 슬라이드
comment 이번 단원은 생식기를 위에서부터 아래로 훑는다: 난소 → 난관 → 자궁 → 자궁목 → 질 → 질어귀·음문. 장기마다 "염증·유착·저류·종양"이 반복되니 어디에 / 무엇이 고였나(물·점액·고름·공기·오줌)로 정리하면 덜 헷갈린다. 수업은 질어귀샘 낭종까지 진행했고, 6. 저수태우는 다음 시간 예정이라 교본 + 보충으로만 정리했다. 교수님이 가장 공들인 건 자궁속막염(원인·종류·진단, 성호르몬과의 관계)과 자궁축농증(황체존속 기전, 임신과의 감별, 치료)이고, 그 다음이 공기질증·요질 처치법이다.

1) 난소

(1) 난소종양 — 과립막세포종

  1. ① 특징: 발정주기 없어짐, 불임증 기출 25-8① · 24-8①
  2. ② 증상: 사모광증, 엉치궁둥인대 이완, 미경산소의 젖 분비 등 → 모두 estrogen 생산과 관련된 증상 필기 수업 (종양의 과립막세포가 에스트로겐을 많이 만들기 때문)
  3. ③ 모양: 단단하고 황색, 다수의 낭포 또는 한 개의 대형 낭포(지름 10cm 이상) — 교과서 사진엔 20cm 이상의 거대한 것도 수업

(2) 난소염 및 난소유착 기출 25-8② · 24-8②

난소 버팀질(stroma)의 염증 = 원인→주위 조직과 유착 = 결과 필기
발생 동물소, 돼지
원인① 물리적인 힘이 가해지는 상황 필기: 직장검사 중 황체를 손으로 제거, 난소의 거친 촉진 수업
② 자궁 염증의 상행성 파급: 자궁속막염, 난관염, 자궁염, 배막염
증상난소 유착 → 난소가 제 기능을 못하기 때문에 필기 배란 저지, 난포의 황체화(낭종) / 만성 → 버팀질 섬유화(딱딱해짐) → 무발정
진단·예후초기: 난소 부종(커짐), 촉진 시 통증 / 예후: 일측성 → 수태 가능(반대쪽이 정상이면), 양측성 → 불량

3) 자궁

(1) 자궁속막염 (endometritis) 체크 기출 23-14 · 22-23 · 21-11 · 25-8 · 24-8

자궁속막의 염증. 자궁 질환 중 가장 많이 발생하며 불임을 유발한다. 원인은 세균 감염(교과서 p.496: 연쇄상구균, 포도상구균, 대장균 등) 수업

① 감염 경로 — 질을 통한 상행성 감염

  1. ㉮ 인공수정·생식기 검사·처치 시 — 세균에 오염된 정액, 수정기구, 검사·처치 기구
  2. ㉯ 난산(dystocia) — 수의사가 꺼내는 과정·처치 중 감염
  3. ㉰ 태반정체 — 태반이 오래 자궁 안에 남으면 염증성으로
  4. ㉱ 공기질증 — 말에서 특징적, 공기와 함께 세균이 상행
  5. ㉲ 산욕기(분만 후 자궁이 회복되는 시기)에 세균 침입 수업

② 자궁 내 세균 감염과 성스테로이드 호르몬

Estrogen자궁의 세균 감염을 저지 (방어) — "에스트로겐이 세균 발육에 적합한 환경" ✗ 기출 25-8④ — 보충: 호중구 유입↑, 자궁 수축↑, 경관 열림 → 배출
Progesterone세균 발육에 적합한 환경 조성 — 보충: 면역 억제, 경관 닫힘, 자궁 수축↓
결과소: 황체기 초기(= 프로게스테론이 생산되고 있는 시기 필기)에 자궁에 세균이 들어가면 → 자궁속막염 수업 기출 24-8④

기타 원인: 소 — 간흡충의 딴곳기생 / 자극성 강한 약액의 자궁 내 주입 / 고온 세척액(온도가 맞지 않는 세척액)으로 자궁세척 수업

③ 종류 수업

급성 vs 만성삼출성 vs 잠재성→삼출성 = 카타르성(탈락조직, 회백색) / 화농성(pus) / 카타르성 화농성(둘이 섞임)

보충: 잠재성(무증상) 자궁속막염은 겉으로 분비물이 없어 놓치기 쉬움 → 저수태우의 숨은 원인.

④ 진단 (p.497) — 직장검사, 질검사, 진단적 자궁세척, 자궁속막 생검, 자궁 안 세균검사

질검사삼출성: 자궁질부~바깥자궁구멍 점막 충혈·울혈, 초자성(유리 같은) 또는 고름 모양 삼출물 누출 / 사진 10-15: 음부에서 회색 삼출물이 흘러내려 바닥에도 떨어짐 수업
