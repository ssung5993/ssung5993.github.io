10-3. 호르몬장애에 의한 불임증 (이어서)

출처 표시 — 필기 교본 위 손필기 · 보충 수의번식학 자료로 채운 내용 · 기출 25-7 2021~2025 중간고사 기출 (25-7 = 2025년 7번) · 태그 없음 = 교본 슬라이드 (이번 주는 녹음 없음 → 수업 태그 없음)
comment 이번 범위는 지난주에 이어 난소낭종 (2)원인~(6)예후를 마무리하고, 발정 이상 → 배란 장애 → 황체 형성부전 → 황체 존속으로 호르몬장애를 끝낸 뒤 3. 사양관리 원인(영양·광물질·발정 발견)과 4. 선천적·유전적 원인으로 넘어간다. 녹음이 없어서 교본 + 손필기 + 보충으로 정리했다. 이름이 비슷한 장애가 많아 헷갈리기 쉬운 단원이라, 각 장애를 "발정주기·배란·황체 중 어디가 고장났나"로 나눠 보면 정리가 된다(그림 1·2). 특히 둔성발정 vs 단발정 vs 지속성 발정, 배란지연 진단 기준(소 48시간), 발육부전황체 vs 낭종성 황체 vs 황체존속, 광물질 결핍별 증상, 백색처녀우병이 시험에 내기 좋다.

2) 난소낭종 (이어서) — 2주차 정리본과 이어짐

(2) 원인직접적 원인: 정상 배란에 필요한 수준의 LH가 뇌하수체에서 충분히 분비되지 않음
· 발생률 젖소 > 육우 — 농후사료 다량 급여가 원인 필기
· 젖분비량 많은 소: 젖분비 최고 시기(분만 후 15~45일)에 최대 발생
· 부신겉질자극호르몬(ACTH), estrogen 처치 = 간접적 원인 필기
· 사료: 알팔파·레드클로버 등 콩과 목초 기출 25-6③ · 22-19② / 유전적 소인(특정 품종) / 계절 겨울 / 연령 4.5~10세(2~5산차)
· 기타 관련: 쌍태분만, 태반정체, 자궁염, 유열, 지방간증후군(젖분비량 많은 소) 기출 25-3① · 24-3①
태반정체 = 새끼를 낳은 뒤 태반도 이후에 배출되어야 하는데 배출되지 않는 것 필기
(3) 증상사모광형(발정 빈번, 불임언덕, 과립층 비후·충혈) / 무발정형(일정 기간 무발정, 징후 극히 미약, 과립층 결손·속난포막 황체화) / 중간형 → 이행형. 혈중 estrogen은 정상 발정소보다 높음
(4) 진단배란 없이 2~2.5cm로 장기간 존속 → 낭종 기출 25-3② / 10cm 이상 → 과립막세포종 (사진: 과립막세포종이 생긴 난소 필기) / 자궁: 벽 연약, 자궁속막염, 자궁목관 확장·이완, 질·음핵·음문 부종 / 낭종성 황체 & 황체낭종: 초음파 황체조직, P4 높음 → 배란 유무 확인 (감별은 progesterone — "Estrogen으로 감별" ✗ 기출 25-3④ · 24-3④)
(5) 치료목표 = 기능성 황체 형성 유도
· 난포낭종: hCG, GnRH, 뇌하수체앞엽성 GTH → hCG 처치 후 2~7일 사이 낭종벽 황체화(또는 파열 후 황체 형성) → 점진적 황체 퇴행 → 정상 난포 발육
· 황체낭종: 마찬가지로 hCG 처치 필기(GnRH, GTH) → 황체화 촉진 → 내인성 황체퇴행인자에 대한 감수성 획득 / PGF2α
기출: 치료제로 쓸 수 없는 것 = "난포낭종 - Progesterone" 기출 25-22 (답지 기준)
(6) 예후조기 발견·치료 → 양호 / 자궁속막의 낭포성 변화·위축(자궁점액증) → 불량

3) 발정 이상

종류: 무발정, 둔성발정, 단발정, 지속성 발정, 무배란성 발정 (무발정은 앞의 난소기능부전·난소낭종, 뒤의 황체존속에서 원인별로 다룸)

(1) 둔성 발정 (silent heat) 기출 25-4 · 24-4 · 22-16 · 21-9

정의난포의 발육, 배란, 황체의 형성 및 퇴행은 정상적(= 발정주기는 정상적 필기)이나 난포의 발육과 배란 시기에 발정이 나타나지 않는 상태
발정 징후: 약한 것 ~ 전혀 보이지 않는 것(무발정 배란)
기출 함정: "난포의 발육과 배란에 이상이 생겨 발정이 나타나지 않는다" = 틀린 선지 기출 22-16① / 25-4①·24-4①의 "난포의 발육과 배란이 나타나지 않는 상태"도 같은 오류 문장(복원 과정에서 "시기에 발정이"가 빠진 것으로 보임)
발생 시기소의 성성숙 시기 1·2·3회째 배란 시, 분만 후 1·2·3회째 배란 시 발생 높음 → 생리적 둔성 발정 / 그 외 = 병적인 둔성 발정
보충: 첫 배란 전에는 황체가 없어 P4 "예열(priming)"이 안 된 상태라, 뇌가 에스트로겐에 반응해 발정 행동을 보이지 못한다.
동물별소: 난소 질환 중 발생률 높음, 젖분비량 많은 소, 포유 중인 육우, 사양관리(실내 사육)
말: 사양관리 조건이 나쁜 경우, 치아 질환·기생충 감염 개체
해결 방법직장검사 등으로 황체의 퇴행, 난포의 발육과 성숙을 확인 → 교배 적기 판정 (발정 행동 대신 난소를 보고 수정)
원인GTH(= Gonadotropin 필기)의 분비 이상 / estrogen·progesterone 분비 이상 또는 양적 불균형 기출 25-4② · 22-16② / 발정 발현 관련 호르몬에 대한 감수성 역치의 상승 / 심리적 요인
진단직장검사·초음파로 난소의 주기적 변화를 관찰하고 발정 발현 유무와 대조 → 7~14일 간격으로 여러 번 검사
치료· 소·말: 황체기에 PGF2α → 황체 퇴행 → 발정 유도 / 발정 예정일 2~3일 전 estradiol 단독 또는 progesterone과 병용 기출 22-16③④ · 24-4⑤
· 말: 자궁세척 기출 25-4④ · 24-4④ — 포비돈 같은 것으로 세척 → 황체퇴행 유도 가능 필기 (보충: 자궁내막이 자극받아 PGF2α가 분비되기 때문)

(2) 단발정

발정주기는 정상, 난포의 발육·성숙 시기에 발정은 있으나 짧은 상태. 보충: 발견을 놓치기 쉬워 실제로는 "발정 발견 실패"로 이어진다.

(3) 지속성 발정

  1. ① 발정이 비정상적으로 길게 지속, 배란장애 동반
  2. ② 발생 과정: 성숙 난포가 장기간 존속 / 난포의 발육·성숙·폐쇄·퇴행이 연이어 계속 발생 / 난포가 낭종으로 이행
  3. ③ 발생 동물: 젖소 — 난포낭종(사모광증) / 말 — 번식계절 초기
  4. ④ 치료: 소·말 발정기에 발육·성숙한 난포를 확인 → hCG 또는 GnRH 유사체(배란 유도) → 인공수정 / 소·돼지: 뇌하수체앞엽성 GTH
기출 포인트 기출 25-4 · 24-4 · 22-16 · 21-9
· "말의 지속발정 치료 = PGF2α" ✗ (25-4③·24-4③) → hCG 1500~3000 IU 또는 GnRH 유사체 후 12~18시간에 인공수정
· "소의 지속발정 치료 = GnRH(25-4⑤) / hCG(22-16⑤)" O
· "소의 지속적 발정 치료 = progesterone" ✗ (21-9⑤, 답지 기준)

4) 배란 장애

종류: 배란 지연, 무배란, 다배란 · 발생 시기: 말과 면양 — 번식계절 초기 · 원인: 배란성 LH surge의 지연·결여·부족, 난소의 유착 → 무배란

종류정의·특징진단·치료
(1) 배란 지연난포가 발육·성숙하고 발정도 오지만 난포가 오래 존속 / 발정 개시부터 배란까지 오래 걸림소: 발정 개시 후 48시간(발정 종료 후 24시간)이 지나도 배란 X → 이러면 배란지연으로 판단 필기
말: 발정 종료 후 배란
(2) 무배란난포 발육·발정 발현은 있으나 배란 없음 → 난포는 폐쇄퇴행, 폐쇄황체화, 낭종화 / = 거짓 발정, 무배란성 발정치료: 지속성 발정과 같음 (hCG·GnRH)
(3) 다배란젖소에서 FSH 방출량 증가 → 불임증
불임 원인: 결함 난자의 다량 배란, 난관 내 난자의 수송 저해, 난자(수정란)의 정상 착상 실패를 유발하는 내분비 장애		보충: 수정란이식의 "과배란 처리"는 이걸 일부러 FSH로 유도하는 것 — 공란우에선 목표, 일반 번식우에선 장애
말의 배란은 원래 발정 끝나기 1~2일 전에 일어나므로, "발정 종료 후 배란"이면 지연이다. 소는 원래 발정 종료 후 약 10~12시간에 배란하는 동물이라 기준이 다르다. 보충

5) 황체 형성부전

정의: 배란 후 형성되는 황체에 황체조직이 불충분하게 발육한 것(황체 형성 저하증) → progesterone 분비 저하 · 종류: 발육부전황체, 낭종성 황체

(1) 발육부전황체

정의황체의 발육이 부진 → progesterone 분비 기능이 불충분한 황체
특징황체 수명이 짧고 발정주기가 짧음
발생 시기소 — 성성숙 및 분만 후 첫 배란 시 황체 / 분만 후 생리적 난소 휴지기(호르몬으로 배란을 유도한 뒤) / 난소낭종 치료 후
원인FSH와 LH 분비 부족 / 배란 전 난포 및 그 후 황체의 LH 수용체 부족 / 자궁의 황체퇴행인자 과잉 또는 조기 생산
진단·치료발육부진한 작은 황체 + 짧은 발정주기 → 배란기 또는 배란 후 hCG, GnRH 유사체 (LH 작용으로 황체 발육 지원)

(2) 낭종성 황체 기출 23-4 · 25-2⑤

발생·형태소 — 황체 형성 초기에 중심부에 내용액이 있는 작은 공간 존재 / 배란 후 황체 개화기에 중심 공간이 현저히 크고 주위 황체조직층이 얇은 황체
특징P4 함량: 정상 개화기 황체와 비슷하거나 낮음 (정상 황체와 유사한 기능)
진단· 배란 후 2~5일, 황체 초기의 정상 황체보다 큼
· 직장검사상 황체층이 얇아 난포·난포낭종과 비슷한 긴장감·파동감
· 초음파상 속 공간은 검게(무에코) 나타남 (사진 10-10)
황체낭종과 구별· 촉진: 낭종성 황체는 정상 황체처럼 배란 부위에 황체조직의 관(crown) 모양 돌출이 있거나 없음 (황체낭종은 배란이 없었으므로 배란점 X)
· 낭종성 황체는 황체 초기에 파열되면 2~3일 안에 발육 좋은 황체로 발육
치료hCG
2주차 "낭종성 황체 = 정상 배란 + 7~10mm 공간, 정상과 유사한 기능"과 같은 대상이다. 이번 단원에선 황체조직층이 얇아 P4가 낮을 수 있는 경우를 황체 형성부전으로 분류한 것. 즉 공간이 작고 벽이 두꺼우면 정상 변이, 공간이 크고 벽이 얇으면 형성부전으로 본다고 정리하면 된다. 보충

6) 황체 존속

정의: 비임신인데 황체가 존속하여 기능을 발휘하는 상태 (= 황체존속, 영구황체) · 특징: 왕성한 progesterone 분비 → 무발정

(1) 원인① 자궁 유래 황체퇴행인자(PGF2α)의 산생·방출 저해: 자궁 내 이물, 만성 자궁속막염, 소 — 태아 미라 변성, 농이나 점액 저류(자궁축농증), 말 — 자궁 세척 시 이물 삽입
② 뇌하수체 GTH 분비 항진: 고농도 GTH → 황체기능 자극 → 황체 존속
"GTH 분비 감소"는 황체존속의 원인이 아님 기출 25-5 · 24-5 — GTH가 줄면 난포·황체가 안 생기는 난소 기능 정지가 됨
(2) 진단· 소·돼지: 무발정 + 기능적인 황체가 장기간 존속 → 7~14일 간격 황체 촉진, 혈중(유즙) P4 3~4일 간격 측정, 초음파(기능성 황체)
· 말: 무발정, 난소 크기 정상, 난포 발육 없고 황체 같은 구조물 의심, 자궁 촉진 시 비임신, 혈중 P4 2 ng/mL 이상 지속
"자궁 내 PGF2α 농도를 측정해 1mg/mL 이하일 때 확진" ✗ → 혈중(유즙) P4로 진단 기출 22-17④
(3) 치료PGF2α: dinoprost, cloprostenol IM 또는 황체가 있는 쪽 자궁뿔 안이나 황체가 있는 난소 실질 안에 dinoprost 주입
· 말 무발정 개체: dinoprost SC 또는 IM
· 돼지: 장기간 무발정 시 eCG 단독이 무효하면 → dinoprost IM, 또는 dinoprost 투여 후 eCG 추가 (근육주사·자궁각 심부·난소 실질 주사 = O 기출 22-17⑤)
