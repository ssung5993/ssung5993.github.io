Ⅰ. 혈청화학 검사란?

1. 검사의 흐름 — sick? → then, where? → how? why? what?

  • 독소·세균·바이러스·외상 등 원인 → 장기(세포) 손상 → 두 갈래로 결과가 나타남
혈청화학 검사의 위치 — 왜 하나? 필기2
  • 아픈 개·고양이가 왔을 때 어디가 아픈지 선별하는 검사 → 혈청화학으로 최소한 어느 장기가 관여됐구나를 평가
  • 여기에 방사선·초음파 + 보호자 history taking을 더해 좁혀감
  • 원인을 꼭 몰라도 대증 치료는 가능 — 구토하면 구토를 멈추는 처치를 하듯이
  • 원인체: 고양이는 바이러스 못지않게 세균이 튀어나오는 경우가 꽤 있고, 강아지는 바이러스가 대부분인 듯? (동기 메모 — "~인 듯?" 추정 표현)
  • Injury = 손상된 세포가 흘리는 무엇~ (주로 효소)
  • Malfunction = 손상된 세포의 기능 이상
✎ Malfunction에 "여기 도달했다? 이미 큰일났다…" 필기
  • 그래서 나이 많은 환축에서 간이 아플 것으로 예상되면 → injury marker + malfunction marker를 같이 검사해야 간 상태를 정확히 평가 필기2
  • 주요 장기에서 단순 손상을 넘어 기능 이상까지 갔다 = 일단 위중, 예후가 안 좋을 수 있음 → 보호자에게 이 의미를 설명할 수 있어야 함 수업
  • 예) 신장: BUN·Cr이 신장 때문에 올랐다 = 기능이 1/3도 안 남았다(2/3 이상 소실)는 뜻

2. Injury marker — 대부분 효소

  • 효소는 농도가 아니라 "활성도(activity)"로 표현 시험
1
  • 이유: 효소를 직접 정량하지 않고, 기질을 넣고 incubation → end product를 재서 간접 평가하기 때문
  • 단위: 효소는 대부분 U/L · TP·albumin만 g/dL · 나머지 화학 항목은 mg/dL 수업
  • 예외: trypsin, cPLI는 효소 자체를 직접 정량 (amylase·lipase는 간접 = 활성도)
  • 췌장 효소가 분해하는 것: amylase = 탄수화물 · lipase = 지방 · trypsin = 단백질 / cPLI = 개 췌장에서 분비되는 특이적 리파제만 면역학적으로 측정한 수치 → 췌장염 마커 필기2

1) 신장 지표가 "배설 기능"을 보는 이유

  • 몸은 세포 덩어리 → 모든 세포는 세포 수준에서 소화·배설이 있음 → 심장이 배설물을 신장으로 날라주고, 신장이 걸러서 모았다 배설 수업
  • 배설을 제대로 하려면 세뇨관 상피세포가 살아서 ATP를 만들어 작동해야 함
  • BUN·Creatinine은 몸 안에서 매 순간 계속 만들어짐 — 자고 있어도!
  • Creatinine: 숨만 쉬어도 횡문근(호흡근)이 움직이니 계속 생성 → Cr = 0은 살아 있는 개체에서 불가능 (→ Ⅴ장 용혈 case)
  • BUN: 단백 대사 → 암모니아 → 계속 생성
  • 신장 연구의 두 방향: ① BUN·Cr이 정말 신장이 망가져서 오른 건지 구별 ② 더 early phase에서 알 수 있는 방법은 없을까 → 그래서 나온 게 SDMA 필기2
  • SDMA: Cr보다 민감 — 신기능 약 30–40% 손상부터 증가(문헌마다 다름), 일종의 배설물
  • 처음 나왔을 땐 수의사들이 열광 → 써 보니 해석 안 되는 상황이 많아 특히 고양이에서 마음이 떠난 수의사도 많음 → 대체 항목이 없어 그냥 사용 중 수업
  • 동물 연구의 한계: 보호자 동의 등으로 n수 확보가 어려움 (사람은 수천~수만 명)
  • 요비중: 땀을 많이 흘리면 비중↑, 물·술 많이 마시면 소변량↑ = 세뇨관의 농축·희석이 작동한 결과 → 농축·희석이 안 되면 신장 기능 손상
  • 교수님 사모님: "산에 가니까 소변이 잘 안 나오네" → 땀 → 농축 수업

3. Accuracy of a test — 민감도·특이도·PPV·NPV

  • 모든 검사엔 골든 스탠다드(표준 검사법)가 있음 — 예: 종양 → 조직병리. 새 검사법은 골든 스탠다드 대비 얼마나 정확한지를 민감도·특이도·PPV·NPV·accuracy로 제시
  • Sensitivity = proportion of true positives detected by the test (질병 있는 군 중 진양성 비율)
  • Specificity = proportion of true negatives detected by the test (질병 없는 군 중 진음성 비율)
  • PPV = likelihood of a positive test being genuine → 필기 '양성' 결과가 나왔을 때 진짜 '양성' 비율
  • NPV → 필기 '음성' 결과가 나왔을 때 진짜 '음성' 비율
  • Accuracy = (TP + TN) / (TP + TN + FP + FN)

4. Hemolysis — 용혈

1) 용혈의 원인

  • 채혈 시 용혈 – 23G, 24G needle
  • 필기 고양이 채혈 때 쓰는 작은 needle인데, 이 때문에 적혈구가 파괴되는 경우 多 — 바늘이 작을수록 시린지를 당길 때 와류 → RBC 잘 깨짐
  • 채혈이 잘 안 돼서 시린지 피스톤을 몇 번 앞뒤로 왔다 갔다 → 음압 변화 → 원심분리하면 여지없이 벌겋게 용혈 (수의사 질문 메일)
  • Handling: 검사지연; 혈청 분리 지연 · 전혈 냉동 · 얼음과 함께~
  • Lipemia 동반: 생체 내에선 혈구 영향 거의 없지만, 튜브 안 정체 → 혈구 약해짐 → 원심분리 중 깨짐 → 고지혈 + 용혈 (흔함)
  • 병적인 용혈 (1학기: 적혈구가 병적으로 깨지는 경우)
  • And more!!!! — hemoglobin-based oxygen carriers(Oxyglobin 등, 합성 Hb 제제, hypoxia 환자) → severe discoloration of plasma → 흡광도 영향 → 다른 항목 오류

2) 용혈의 영향 — 영향 severe!!

  • 세포가 깨지면 세포 내 물질이 나옴: K, P, AST, LDH, CK, Bilirubin, Hb (K·P = 세포 내 주된 이온)

  • CK(CPK)는 RBC 안에 있진 않지만, RBC 안의 다른 효소(adenylate kinase)가 CK 측정에 간섭 → CK↑
  • 실제 용혈 환자에서 이 항목들이 다 균일하게 오르진 않음

*헷갈리기 쉬운 짝
  • 활성도 vs 농도 — 효소(ALT, AST, ALP, amylase, lipase)는 활성도(U/L), 단 trypsin·cPLI는 직접 정량

  • Injury vs Malfunction — 신장은 injury marker 없음, BUN·Cr·SDMA·SG 모두 기능(malfunction) 지표
  • 간 malfunction 40–50% vs 85% — NH₃·bile acid·bilirubin은 40–50% 손상부터 / albumin·BUN·glucose·chol(합성)은 85% 이상에서야 감소

  • EDTA vs Heparin — EDTA = CBC(전혈) / heparin = chem(혈장). EDTA를 chem에 쓰면 Ca↓ K↑ ALP↓
  • Lipemia vs Hemolysis 색 — milky(우윳빛, TG↑) vs 붉은색 / 황달 = 누르스름 / 정상 = straw
  • Wet vs Dry vs Semi-wet — 랩·액상·간섭 多 / POC·건조 시약·개별 검사 / 로터 카트리지 통째 검사(한국 비선호)
