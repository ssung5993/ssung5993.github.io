Ⅲ. BUN (blood urea nitrogen)

1. 특징

  • 포유류의 주요 질소 노폐물 / 신장에서 배설 / 작은 분자량, no charge, no protein binding → 몸 전체에서 자유롭게 이동, 평형이 빠름
  • 대사: 장(colon)에서 dietary·bacterial·cellular 단백질 → protease·urease → NH₃ → portal circ.(~85%) → 간 urea cycle → urea → 신장 배설(~75%) / 일부(~25%)는 장으로 다시 배출
  • 주된 source = 식이 단백질 + 내인성 아미노산 대사 수업
  • 필기 *BUN은 Creatine 냅두고 혼자 값이 증가할 수도 있음 (Cr은 "순수한(?) 신전성")

Ⅺ. 해석 함정 — Non-creatinine chromogen · 고양이 USG

1. Non-creatinine chromogen

  • Jaffe 법: Creatinine + Picrate →(OH⁻)→ red–orange color (Janovsky complex)
  • Jaffe 법으로 검사할 때 시약과 반응하는 Cr 외 물질: acetoacetate, glucose, vitamin C, uric acid, pyruvate, cephalosporin, AA… → Cr이 오를 상황이 아닌데 Cr↑

  • 이 물질들은 요에는 없음 → 요 Cr 검사는 정확

2. CKD and urine concentration — 고양이 주의

  • dog, SG – 1.030 / cat, SG – 1.035, but……
