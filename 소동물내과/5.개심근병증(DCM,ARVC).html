Ⅰ. 심근병증의 분류 Cardiomyopathy (WHO)

  • Dilated CM (DCM) — 확장성
  • Hypertrophic CM (HCM) — 비대성
  • Restrictive CM (RCM) — 제한성
  • Arrhythmogenic RV CM (ARVC) — 부정맥 유발성 우심실
  • Unclassified CM — 미분류
  • Specific CM — 원인이 명확한 2차성 (예: Adriamycin(doxorubicin) 독성)
Cats and dogs are different!!! 시험
  • 개: DCM이 가장 흔함 (dilated, most common in dogs) → 그다음 HCM(± 폐쇄성), ARVC(Boxer), RCM, 미분류
  • 고양이: HCM이 대부분 → 다음 강의
  • 같은 "심근병증"이라도 종에 따라 흔한 형태·원인·치료가 다름
Different and unknown — 아직 모르는 게 많은 병
  • 근본적으로 미지(fundamentally unknown): 역학(epidemiology) · 자연 경과(natural history) · 원인(etiology) 모두 불명확, 유전 연구는 진행 중
  • 과학적 근거 자료가 아직 "기술(descriptive)" 수준에 머묾 → 그래서 교과서마다 숫자·분류가 조금씩 다름
"심근병증"의 의미 — 판막병·선천성 기형과 무엇이 다른가
  • 1장(선천성)·4장(MMVD)은 구조물(구멍·판막)이 고장 나서 피의 흐름이 틀어지고, 그 부담을 심근이 떠안는 병
  • 심근병증은 거꾸로 펌프 근육 자체가 1차 고장. 판막·혈관이 멀쩡해도 근육이 약하거나(DCM) 두꺼워지거나(HCM) 굳거나(RCM) 전기적으로 불안정(ARVC)
  • Adriamycin이 "specific"인 이유: 원인이 분명함. 독소루비신은 심근세포 미토콘드리아에서 활성산소를 만들고, 심근은 항산화 효소가 적어 손상이 누적 용량에 비례해 쌓임 → DCM과 비슷한 모양으로 끝남 원리

Ⅱ. 개의 확장성 심근병증 Canine Dilated Cardiomyopathy

1. 정의 시험

Inherent disease of the myocardium that results in a decrease in myocardial contractility — 심근 자체의 내재적 질환으로 수축력이 떨어지는 병

  • 대부분 유전적 이상일 가능성 — 주로 순종견(purebred)에서
  • 병은 아마 태어날 때부터 있고, 그때부터 서서히 진행 (present at birth → slowly progresses)
  • 영양성 원인: 타우린 결핍(taurine deficiency) → Ⅹ장
  • 질병을 정의할 때는 핵심 단어가 들어가야 함 → DCM = 심근이 얇아짐 + 편심성으로 바깥으로 퍼짐 + 수축(systolic) 기능 장애 수업
"태어날 때부터 있는데" 왜 중년이 돼서야 증상이 나오나
  • 심장은 예비력이 큼. 수축력이 조금 떨어져도 보상기전(교감신경 → 심박·수축력↑, RAAS → 체액량↑, 심실 확장 → Frank-Starling)이 박출량을 정상처럼 맞춰 줌
  • 이 시기 = 잠복기(occult / preclinical DCM): 겉으론 멀쩡, 초음파·Holter로만 이상이 보임 → 그래서 Doberman은 선별검사를 함(Ⅴ-3)
  • 보상이 한계를 넘는 순간(보통 중년 이후) 갑자기 심부전 또는 부정맥 증상으로 내원 → 보호자 입장에선 "갑자기 생긴 병"
그림 2. DCM 자연 경과 — 긴 잠복기 후 갑자기 드러남 (개념도)

2. 신호 (Signalment)

  • 대부분 중년~노령견이 심부전 상태로 내원
  • 더 일찍 발견되는 경우: 선별검사(screening)를 했거나, 증상을 일으키거나 청진에서 들리는 부정맥이 먼저 생긴 경우
  • 대형·거대견은 소형견보다 수명이 짧아서 5–6살이면 이미 중·노령으로 분류 수업
  • 성별: 반성 유전(sex-linked)은 아니지만 수컷 우세처럼 보임 → 수컷이 더 빨리 진행, 더 심한 경향 (증거는 없지만 같은 DCM이라도 수컷이 더 빨리 더 나쁜 상태로) 시험

왜 순종 · 대형견에 몰리나 정리자 보충
  • 순종 = 적은 수의 조상에서 근친 교배 → 특정 유전자 변이가 집단 안에 농축. 실제로 Doberman에선 PDK4·titin 유전자 변이, Boxer ARVC에선 striatin 변이가 보고됨(모든 개체를 설명하진 못함)
  • 대형견의 심장은 원래 크고, 큰 심실 = 벽응력(Laplace)이 큰 상태로 평생 일함 → 근육이 약하면 더 빨리 무너짐 (Ⅲ장 원리)

Ⅲ. 병리 — 어떻게 생긴 심장인가

심실 단면 비교 — 정상 vs DCM vs HCM (모식도)
  • 정상 심근 두께 비율: RV 1 : 심실중격(IVS) 3 : LV 자유벽 3 정도 필기 수업
  • DCM 부검 심장: 세 벽 두께가 비슷비슷해짐 = LV·중격이 얇아짐 + 심실 내강이 편심성으로 바깥으로 퍼짐 → 공처럼 둥근 심장 수업
  • 기능적으로는 수축이 안 되는 systolic dysfunction 시험
3
왜 "커지는데 얇아지나" — 편심성 확장과 Laplace 법칙
  • 4장 MMVD처럼 심실이 커질 때는 근세포가 직렬로 근절을 추가(길어짐) → 내강↑. MMVD는 "피가 너무 많이 들어와서" 늘어나고, DCM은 "못 짜내서 남은 피 + 보상용 체액 증가" 때문에 늘어남
  • 근육 총량이 같거나 줄어든 상태로 풍선이 커지니 벽이 얇아짐. MMVD 보상기엔 벽 두께가 어느 정도 유지되는데, DCM은 근육 자체가 병들어 있어 두꺼워질 능력이 부족
  • Laplace: 벽응력 ∝ 압력 × 반지름 / 벽 두께 → 반지름↑ + 두께↓ = 벽응력↑↑ → 근세포 하나하나가 더 세게 버텨야 함 → 산소 소모↑ → 근세포 손상·섬유화 → 수축력 더↓ → 더 늘어남 = 악순환
수축력↓ (1차)→ESV↑ (못 짜냄)→RAAS·교감 → 체액↑→EDV↑ (확장)→반지름↑·벽 얇아짐→벽응력↑→수축력 더↓

세 부정맥이 왜 이렇게 다른 무게를 갖나
  • AF가 거대견에 흔한 이유: 세동은 심방 안에 작은 재진입 회로 여러 개가 동시에 돌아야 유지됨 → 그만큼의 "공간(임계 질량)"이 필요. 거대견 심방은 원래 크고, DCM으로 LA까지 커지면 AF가 자리 잡기 쉬움 (3장 AF 원리)
  • AF가 덜 치명적인 이유: 심실은 여전히 규칙적인 전도계를 통해 수축. 잃는 건 심방 수축(atrial kick)과 리듬 규칙성 → 박출량은 줄지만 바로 죽지는 않음. 문제는 너무 빠른 심실 반응 → 그래서 치료 목표는 "리듬 복원"보다 심박수 조절(rate control)
  • VT가 치명적인 이유: 심실이 너무 빨리 뛰면 이완기가 짧아 채울 시간이 없음 → 박출량 급감 → 뇌 관류↓ = 실신. 늘어나고 섬유화된 DCM 심근은 전기적으로 불균일 → VT가 VF로 무너지면 = 돌연사
  • 서맥이 "말기"인 이유: 저산소·산증·전해질 이상으로 동방결절·전도계마저 지치면 자동능이 꺼짐 → 심장이 멈추기 직전의 리듬

1. Holter로 본 돌연사 과정 수업

정상 리듬 (Lead II)→VPC 산발→다형성 · bigeminy→VT→VF (거친 → 미세)→사망

1. M-mode — FS 계산 필기

LV M-mode 모식도 — 중격(위)과 자유벽(아래)이 수축기에 얼마나 다가오나
  • M-mode = 초음파 빔 한 줄을 시간에 따라 펼친 것 → LV가 얼마나 잘 수축하는지 1차원으로 분석 수업
  • 정상: 수축기에 중격과 자유벽이 크게 가까워짐 / DCM: 거의 수축하지 않음 → 단축률 15–20% 미만 수업
  • FS = (EDD − ESD) / EDD × 100
ESD가 "1차", EDD가 "2차"인 이유 — 순서를 이해하면 외울 필요 없음
  • ESD는 "얼마나 작게 짜낼 수 있나" = 수축력(+후부하)의 결과 → 근육이 약해지면 가장 먼저 커짐
  • ESD만 커지면 SV(EDV − ESV)가 줄어듦 → 몸이 이를 감지 → RAAS로 체액↑ + 심실 리모델링 → EDD를 키워서 차이를 다시 벌림 = 보상
  • 큰 풍선은 조금만 줄어도 많은 양이 빠짐 → FS가 10%대여도 SV는 한동안 유지 가능 → 그래서 "FS 낮은데 증상 없음"이 잠복기의 모습
  • 대비: MMVD(4장)는 EDD↑인데 ESD는 정상 → FS가 오히려 ↑(> 50%). DCM은 ESD↑가 먼저 → FS ↓. 둘 다 "심장이 큰 개"지만 FS로 바로 갈림

  • 부정맥이 있으면 Holter로 심실성 부정맥이 얼마나 심한지 보고 → 항부정맥제를 얼마나 써야 할지 결정. 요즘 Holter는 꽤 쉽게 적용 수업
왜 Doberman은 초음파 + Holter 두 가지를 다 하나
  • Doberman DCM은 전기적 이상(VPC)이 구조적 이상(확장)보다 먼저 나타나는 경우가 많음 → 초음파가 정상이어도 Holter에서 VPC가 쏟아질 수 있음
  • Doberman의 첫 증상이 돌연사일 수 있음 → 심부전 증상을 기다리면 늦음 → 무증상일 때 찾아야 함
  • 짧은 진료실 ECG(1–2분)는 하루 VPC 50개를 거의 못 잡음 (평균 30분에 1개) → 24시간 기록이 필요한 이유

4. 기능성 승모판 역류 (Functional MR) — Central jet sign 시험

승모판 모식도 — 왜 DCM의 역류는 "가운데"로 뿜어지나
  • 정상: 판막엽이 잘 접합(coaptation) / DCM: 심장이 중격 쪽 · 자유벽 쪽 · 심첨 쪽 모든 방향으로 확장 → 판막엽 사이가 멀어짐 수업
  • 판막엽·건삭은 태어난 그대로 정상인데 바깥 틀이 벌어지니 → 닫혀도 가운데(central)에 틈(orifice)이 생김 → 중심성 제트 = central jet sign 필기 "LV의 eccentric hypertrophy로 인해 valvular orifice의 형성 → central jet"
  • 역류량: MMVD보다 상대적으로 적음 (MMVD는 판막 자체가 변성돼 꺾이므로 훨씬 많음) 수업
  • 역류 속도는 MMVD와 큰 차이 없음 — 어느 쪽이든 LV–LA 압력차가 비슷하니까 수업

속도는 "양"이 아니라 "압력차"가 정한다 — 단순화 Bernoulli
  • ΔP = 4v² → 역류 속도는 구멍 크기나 역류량이 아니라 LV와 LA의 수축기 압력차로 결정 (1장 VSD 원리와 동일)
  • LV 약 100–120, LA 약 10–20 mmHg → ΔP ≈ 100 → v ≈ 5 m/s. MMVD든 DCM이든 이 압력 구도는 비슷하므로 속도도 비슷
  • 다만 DCM 말기에 LV가 압력을 잘 못 만들고 LA압이 높으면 ΔP가 줄어 약간 느려질 수 있음 정리자 보충
  • 역류량이 적어도 DCM에선 이미 약한 LV가 더 손해 → 앞으로 나가는 박출량↓ + LA·폐정맥압↑ → 악순환에 기름

5. Gallop sound (S3) 필기 3음성 gallop

  • DCM에선 S3 gallop이 보통 들림 → "떡 떡 떡" 하는 말발굽 리듬 수업
  • LV가 커지면서 깊어지고 넓어져, 이완기 초기에 혈액이 떨어질 때 공명이 일어나 생김 수업
그림 3. S3 vs S4 — 언제 들리나
S3는 언제 · 왜 나나 (S4와 구분)
  • S3 = 이완기 초기 급속 충만기. LA압이 높아 피가 세게 쏟아지는데, 이미 꽉 찬 · 늘어난 심실이 더 받지 못하고 갑자기 멈춰 세움 → 심실벽·판막 장치가 진동 = 저음. 개에서 들리면 대부분 비정상 → DCM·용적 과부하의 신호
  • S4 = 이완기 말기 심방 수축 때 뻣뻣한(두꺼운) 심실로 피를 밀어 넣는 소리 → HCM(고양이)에서 더 전형적. AF면 심방 수축이 없으니 S4도 없음
  • 둘 다 저음이라 청진기 벨(bell)로, 심첨부에서 더 잘 들림. 4장의 systolic click(고음, 수축기)과 혼동 주의

6. EPSS (E-Point to Septal Separation)

승모판 M-mode 모식도 — E점(최대 개방)과 중격 사이 거리
8
  • 승모판 M-mode에서 판막이 이완기 초기에 최대로 열린 점(E point)과 심실중격(septum) 사이 거리 → DCM에선 증가 (확장되니까) 수업
  • E파(이완기 초기 수동 충만) 다음 A파(심방 수축) → M자 모양
EPSS가 늘어나는 두 가지 이유
  • ① 공간: LV가 커져 중격이 판막에서 멀리 밀려남
  • ② 흐름: 수축력이 약하면 1회 박출량이 적고 → 그만큼 다음 이완기에 승모판을 통과하는 혈류도 적음 → 판막엽이 덜 크게 열림
  • → 정상 개는 E점이 중격에 거의 닿을 정도로 크게 열림. EPSS는 "수축력↓ + 확장"을 동시에 반영해서 FS와 함께 DCM 진단의 핵심 체크

7. LA 확대 평가

  • LA/Ao ratio 또는 LA/Ao 면적비로 평가 (기준값은 4장 표 18: ratio 정상 < 1.5, 면적비 < 3.5)
  • DCM에서도 기능성 MR이 있어 LA가 커짐 → 심부전일 땐 심하게 확대

Ⅶ. 치료 Treatment

DCM은 심근병이지만 심부전 = 혈액 흐름의 문제이므로 심부전 치료가 당연히 들어감. 기본 컨셉 = 이뇨제 + RAAS 억제제, 그리고 DCM은 수축력이 떨어진 병이라 양성 수축력 강화제(pimobendan)가 반드시 들어가야 함 수업

Furosemide (울혈↓)+ACEI (RAAS↓)+Pimobendan (수축력↑ · 혈관 확장)±항부정맥제

1. 전통적 심부전 치료 (Conventional HF therapy) 시험

고양이 심혈관계는 수분(fluid)이 들어오고 나가는 것에 개보다 훨씬 민감 → 조금만 더 들어와도 금방 폐수종, 조금만 더 빠져도 금방 심한 탈수 → 신장 쪽에 AKI. 그래서 개 용량을 고양이에 똑같이 적용하지 않음

Furosemide 효과 판정 — 가장 쉬운 방법 수업
  • ① 호흡수: 폐수종으로 호흡곤란이면 호흡이 빠름 → 치료 전 대비 얼마나 정상에 가깝게 줄었나
  • ② 흉부 X-ray: 폐수종 개선을 눈으로 확인 (Ⅵ장 치료 전후 사진)
  • 집에서는 보호자가 안정 시·수면 시 호흡수를 세어 기록하는 것이 일반적 모니터링 방법 정리자 보충
각 약이 DCM 병태의 어디를 치나
  • Furosemide (루프 이뇨제): 헨레고리 굵은 상행지의 Na-K-2Cl 운반체 차단 → Na·물 배설↑ → 체액량·전부하↓ → LA압·폐정맥압↓ → 폐수종 해소. 수축력은 못 고침 = "증상(울혈)" 치료
  • ACEI: Angiotensin II·알도스테론↓ → Na·물 저류↓ + 혈관 수축↓(후부하↓) + 장기적으로 심근 섬유화·리모델링 억제 (Ⅲ장 악순환 늦추기)
  • Pimobendan: 유일하게 "약한 근육" 자체를 도와줌 → 아래 2번

2. Pimobendan — 왜 DCM의 필수 약인가 시험

Pimobendan 작용 모식도 — inodilator (수축력↑ + 혈관 확장)
표 11. 슬라이드 요약
Potent positive inotrope① Phosphodiesterase(PDE3) 억제 ② 수축 단백의 Ca²⁺ 감수성↑ (calcium sensitizer)
Mild vasodilatorPDE 억제 → 말초 혈관 확장
효과생존 기간 개선, 특히 Doberman에서
  • 보통 심장 수축력이 올라가면 말초 혈관 쪽 저항·혈압이 올라감. 피모벤단은 수축력을 올리면서 말초 혈관을 확장시키므로 혈압 상승 폭이 크지 않음 → "상당히 이상적인 메커니즘" 수업
  • 요즘 매우 많이 씀: MMVD, DCM은 당연히, 심지어 HCM 말기(수축 기능이 떨어진 end-stage)에도 효과가 있다고 함 수업
그림 5. 약한 심실은 전부하엔 둔하고 후부하엔 예민하다
11
"Ca 감수성↑"가 왜 중요한가 — 같은 힘을 더 싸게
  • 수축의 최종 스위치 = Ca²⁺가 트로포닌 C에 붙는 것. 보통 수축력을 올리려면(교감신경·순수 PDE 억제제) 세포 안 Ca²⁺ 양 자체를 늘림 → 산소·ATP 소모↑ + Ca 과부하로 부정맥 위험↑ → 약한 DCM 심근에겐 독이 될 수 있음
  • Pimobendan은 트로포닌 C가 같은 Ca²⁺에 더 잘 반응하게 만듦 → Ca를 크게 늘리지 않고도 수축력↑ → 에너지 효율이 상대적으로 좋음
  • 혈관 확장(후부하↓)이 DCM에서 특히 이득: 약한 심실은 Frank-Starling 곡선이 납작해서 전부하를 늘려도 박출량이 잘 안 늘지만, 후부하에는 매우 민감 → 뒤에서 미는 저항만 줄여도 박출량이 눈에 띄게 늘고 기능성 MR(뒤로 새는 양)도 줄어듦
  • 슬라이드 사진의 "Help PROTECT Dobermans" = 무증상(잠복기) Doberman DCM에 피모벤단을 쓰면 심부전·돌연사 발생이 늦춰지고 생존이 늘었다는 연구(PROTECT study) 홍보 정리자 보충

3. 항부정맥 치료 (Antiarrhythmic therapy) 시험

  • AF: 심방은 어차피 세동 → 심실로 넘어가는 신호 수를 AV 결절에서 줄이는 게 목표. Digoxin = 미주신경 긴장↑로 AV 전도↓ + 약한 양성 변력(약한 심장에 유리). 단독으론 부족해 β차단제나 diltiazem을 더함

Pacemaker vs ICD 수업

만성 심부전에서 계속 켜진 교감신경은 장기적으로 심근 독성(리모델링·부정맥) → 사람에선 아주 낮은 용량부터 천천히 올려 이득을 봄. 하지만 β 차단은 단기적으로 수축력을 깎음 → 개 DCM은 진단 시 이미 말기인 경우가 많아 그 "적응 기간"을 버티기 어렵고, 아직 연구 근거도 부족 정리자 보충

사망 형태① 돌연사 — Doberman의 20% ② 심부전 (자연사 또는 안락사)
  • 심부전이 있는 DCM은 상태가 안 좋고 당장 내일, 하룻밤 자는 사이에도 죽을 수 있다 → 이런 심각한 질병이라는 걸 보호자에게 꼭 이해시켜야 함 수업
  • 기본 사망 모드: 부정맥에 의한 돌연사 / 심부전에 의한 호흡곤란 수업
MMVD(6개월–2년)보다 예후가 훨씬 나쁜 이유
  • MMVD는 판막 문제라 심근은 오랫동안 튼튼 → 약으로 폐수종을 조절하면 꽤 오래 버팀. DCM은 엔진 자체가 고장 → 약으로 보조할 뿐 근육은 계속 나빠짐
  • DCM은 잠복기가 길고 조용해서 증상이 나올 땐 이미 보상이 다 소진된 말기
  • 늘어나고 섬유화된 심근 = 부정맥의 온상 → 심부전을 잘 조절해도 언제든 VT·VF 돌연사 가능

Ⅸ. Boxer 심근병증 — ARVC Arrhythmogenic Right Ventricular Cardiomyopathy

  • "Boxer cardiomyopathy" — 미국에서 Boxer를 많이 키워 상대적으로 많음 수업
  • Boxer에서 실신(syncope)할 때 나타나는 전형적인 심실 빈맥
이름 풀이 — 왜 "우심실" "부정맥 유발성"인가 정리자 보충
  • 주로 우심실 심근이 지방·섬유 조직으로 바뀜(fibrofatty replacement). 건강한 근육 사이사이에 전기가 안 통하는 조직이 끼면 → 전기가 돌아서 가는 재진입 회로가 생김 → VPC·VT
  • 그래서 펌프 기능은 멀쩡해도(초기) 전기적으로만 불안정할 수 있음 → "부정맥 유발성"
  • VPC가 우심실에서 시작되면 흥분이 오른쪽 → 왼쪽으로 퍼짐(LBBB와 같은 방향) → Lead II에서 QRS가 위로(양성) 넓게 나옴 → Boxer VPC의 전형적 모양 (슬라이드 ECG도 Lead II 양성 VT)
13

2. 심한 심실 빈맥 (Severe VT) — R on T 시험

표 16. ARVC의 VT 특징
심실 초점여러 속도로 발화 가능
심실 초점 속도흔히 > 300 bpm — 대형견에서 300이면 상당히 빠른 수치 수업

R on TR파와 T파가 겹친 형태 → R-on-T 현상
결과가볍게는 실신, 심각하게는 돌연사 수업
R on T가 왜 위험 신호인가
  • T파 = 심실 재분극 중. 이 순간 심근 일부는 이미 회복했고 일부는 아직 불응기 → 전기적으로 가장 불균일한 시기(취약기, vulnerable period)
  • 여기에 다음 흥분(R)이 떨어지면 회복된 곳으로만 전기가 흘러 들어가 제멋대로 도는 회로 → VF로 넘어가기 쉬움 → 돌연사
  • VT가 너무 빨라서 다음 R이 앞의 T 위에 얹힐 정도 = 이완기가 거의 없음 → 박출량↓ → 실신 (Ⅳ장 원리)

3. 치료 시험

표 17. ARVC 치료
VT에 의한 실신Sotalol 40–120 mg BID — "이 병의 기적의 약(miracle drug)"
Sotalol에 불응이면 mexiletine 추가
심부전"The usual suspects" — 늘 쓰던 약 (furosemide + ACEI …) 수업
  • Sotalol을 더 추천하는 이유: mexiletine보다 돌연사 위험률이 더 낮고 더 안정적 수업
  • 용량이 mg/kg가 아니라 마리당 mg (40–120 mg BID) 으로 적혀 있음에 주의 정리자 보충
왜 ARVC엔 sotalol이 "기적의 약"인가 (DCM에선 조심하면서)
  • Class III(K 차단): 활동전위·불응기 연장 → 재진입 회로가 돌아올 때 조직이 아직 불응 상태 → 회로가 끊김
  • Class II(β 차단): 운동·흥분 때 교감신경이 부정맥을 촉발하는 것을 막음 (Boxer 실신은 흥분·운동 중 흔함)
  • ARVC ①형은 LV 수축 기능이 정상 → β 차단의 음성 변력을 감당할 수 있음. 그래서 "LV 기능이 정상인 Boxer"라는 조건이 붙음 (Ⅶ-3과 연결)

Ⅹ. American Cocker Spaniel — 타우린 결핍성 DCM

  • 혈장 타우린 농도가 일관되게 낮음 (< 50 nmol/ml) — 원인 불명 시험
  • 정상인 American cocker spaniel도 혈중 타우린이 낮게 유지 → 영양적으로 불균형하게 되면(장시간 노출) 타우린 결핍 때문에 DCM이 올 수 있음 필기 "타우린 농도↓ → DCM?", "영양학적으로 불균형하게 되면" 수업
  • 타우린 단독 또는 타우린 + 카르니틴 투여로 심근 기능 개선
  • 개선 정도는 고양이만큼 크진 않지만, 보통 심부전 약이 더 이상 필요 없을 정도까지 좋아짐
  • 예전 DCM을 잘 몰랐을 때는 DCM에 걸려 와도 해결책을 찾기 어려웠음 → 임상에서 코카 DCM이면 타우린 측정을 꼭 생각할 것 수업
그림 7. 타우린과 카르니틴이 심근세포에서 하는 일

타우린이 심근에 왜 필요하고, 왜 "되돌릴 수 있는" DCM인가
  • 타우린은 심근세포 안에 가장 많은 유리 아미노산. 세포 삼투압 조절, Ca²⁺ 처리(근소포체 Ca 저장·방출 조절), 항산화에 관여 → 부족하면 Ca를 제대로 다루지 못해 수축력↓
  • 세포가 죽은 게 아니라 "원료 부족"으로 일을 못 하는 상태라, 원료를 채우면 기능이 돌아옴 → 유전성 DCM과 달리 가역적. 단, 이미 섬유화된 부분은 회복 안 됨 → 그래서 고양이보다 회복 폭이 작을 수 있음
  • 고양이는 타우린 합성 능력이 매우 낮아 식이 필수 → 예전엔 고양이 DCM의 주원인이었지만 사료에 타우린을 넣은 뒤 크게 줄어듦. 개는 원래 시스테인·메티오닌으로 합성 가능하지만 일부 품종(코카 등)은 취약
  • 카르니틴: 지방산을 미토콘드리아로 운반 → 심근의 주 에너지원(지방산 산화) 공급 → 에너지 생산을 같이 보충
  • 최근엔 일부 grain-free·콩류 위주 사료와 개 DCM의 연관성도 보고되어 식이력 청취가 중요해짐 정리자 보충

✎ 원리 셀프체크 — 답을 가리고 설명해 보기
Q1. DCM이 "태어날 때부터" 있는데 왜 중년이 돼서야 증상이 나올까?
→ 교감신경·RAAS·심실 확장(Frank-Starling) 같은 보상기전이 박출량을 오래 유지 → 긴 잠복기 → 보상이 소진되면 심부전·부정맥으로 갑자기 드러남.
Q2. DCM에서 ESD가 먼저 커지고 EDD가 나중에 커지는 이유는?
→ 수축력↓ → 다 못 짜내서 ESD↑(1차). 그러면 SV가 줄어 몸이 체액을 늘리고 심실을 키워 EDD↑(2차)로 SV를 다시 맞춤.
Q3. 심장이 커진 개 두 마리. A는 FS 55%, B는 FS 14%. 각각 무엇을 의심?
→ A = 용적 과부하에 수축력은 보존(MMVD 등). B = 수축력 저하 = DCM, 그것도 심부전 수준(< 15%).
Q4. DCM의 MR 제트는 왜 가운데로 뿜어지고, 속도는 MMVD와 왜 비슷한가?
→ 판막엽은 정상인데 LV·판막륜이 사방으로 벌어져 가운데에 틈이 생김(central jet). 속도는 LV–LA 압력차(ΔP = 4v²)가 정하는데 그 차이가 비슷하니까.
Q5. 커지고 얇아진 DCM 심장이 스스로 더 나빠지는 악순환을 Laplace로 설명하면?
→ 벽응력 ∝ 압력 × 반지름 / 두께. 반지름↑·두께↓ → 벽응력↑ → 산소 소모↑ → 근세포 손상·섬유화 → 수축력↓ → 더 확장.
Q6. 거대견 DCM에서 AF가 흔한데, 왜 VT보다 덜 무서워하나?
→ AF는 큰 심방(임계 질량)에서 잘 유지되지만 심실은 전도계로 계속 수축 → atrial kick만 잃음. VT는 이완기 소실로 박출량이 급감하고 VF로 넘어가 돌연사.
Q7. Pimobendan은 수축력을 올리는데도 혈압이 크게 안 오르는 이유는? DCM에서 혈관 확장이 특히 좋은 이유는?
→ PDE3 억제로 말초 혈관도 확장(inodilator). 약한 심실은 후부하에 매우 민감해서 저항만 줄여도 박출량↑ + 기능성 MR↓.
Q8. Doberman 선별에 초음파만으로 부족한 이유는?
→ VPC(전기적 이상)가 확장보다 먼저 올 수 있고 첫 증상이 돌연사일 수 있음 → Holter(> 50 PVCs/24h)를 같이 봐야 함.
Q9. Sotalol은 ARVC의 "기적의 약"인데 수축력 나쁜 DCM에선 왜 조심하나?
→ Class II(β 차단) 성분의 음성 변력 → 이미 약한 LV를 더 약하게 할 수 있음. ARVC ①형은 LV 기능이 정상이라 감당 가능.
Q10. 실신하는 Boxer의 ECG에서 R-on-T가 보였다. 왜 위험한가?
→ T파(재분극) 시기는 심근 회복이 불균일한 취약기 → 그때 흥분이 떨어지면 VF로 넘어가기 쉬움 → 돌연사.
Q11. American cocker의 DCM은 왜 약을 끊을 정도로 좋아질 수 있나?
→ 세포가 죽은 게 아니라 타우린(Ca 처리·삼투 조절) 부족으로 기능을 못 하던 것 → 원료를 채우면 회복(단, 섬유화된 부분은 회복 X).
Q12. 고양이에게 개의 furosemide 용량을 그대로 쓰면?
→ 고양이는 수분 변화에 민감 → 과도한 이뇨로 금방 심한 탈수·AKI. (반대로 수액을 조금만 더 줘도 폐수종)
18
