Ⅰ. PDA — 동맥관개존증 ★

  • 병인: 동맥관 벽에 평활근↓ · 탄력섬유↑ → 출생 후 수축 못 함 (💡 닫는 힘 = 평활근의 능동 수축)
  • 병태: 하행 Ao → PA (압력차 ~100) → 폐순환↑ → LA·LV 용적 과부하 → 좌심 CHF + 부정맥. 사망 = 폐수종 or 부정맥
  • 임상: 무증상 많음 / 연속성(machinery) 잡음, left base, thrill / bounding(waterhammer) 맥 (💡 이완기에 PA로 run-off → 맥압↑)
  • 연속성 → 수축기 잡음만 남으면 = 폐동맥압↑(이완기 압력차 소실) 신호

Ⅴ. TOF — 팔로사징 ★

  • 4요소: ① VSD ② PS ③ 우측편위(걸터앉은) 대동맥 ④ RV 비대 — 💡 원추 중격이 앞·오른쪽으로 치우친 "한 번의 실수"
  • PS 중증도가 방향 결정: mild = 좌→우("pink") / moderate = 순단락 없음 / severe = 우→좌 → 청색증·적혈구증가증
  • 운동 시 청색증 뚜렷 (💡 SVR↓ → 대동맥 쪽이 쉬운 길 + 누두부 조임↑)
  • 잡음: 우측 흉골 경계 holosystolic(VSD) / left base 박출성(PS) / 무잡음 가능(과점도)
  • X-ray: reverse D, 과소순환, PA 정상~작음(단독 PS는 볼록) / 검사: PCV↑, PaO₂↓
  • 치료: 완전 교정(바이패스, 현실적 어려움) / 고식적 단락술(좌쇄골하동맥→PA = 인공 PDA) / PS 풍선 / 운동 제한
  • 지지: 사혈(PCV > 75% → 60–65%, 💡 정상까지 낮추면 산소 운반↓) · hydroxyurea · β-blocker(저산소 발작↓)
사혈량 공식 ★

(BW × 0.09 × 1000 mL) × (실제 PCV − 목표 PCV) ÷ 실제 PCV — 예) 10 kg, 78 → 62%: 900 × 16/78 ≈ 185 mL

*헷갈리기 쉬운 짝
  • PDA 맥 bounding ↔ SAS 맥 약하고 늦게 / 연속성(PDA, S2 최대·안 끊김) ↔ to-and-fro(SAS·VSD+AR, S2에서 끊김)
  • VSD → 좌심 커짐(RV 통로) ↔ ASD → 우심 커짐(LA 통로) / 단독 PS PA 볼록 ↔ TOF PA 작음
  • PS 풍선 효과 좋음 → 스텐트 ↔ SAS 풍선 단기뿐 / PS 예후 CHF ↔ SAS 예후 돌연사
  • 좌→우 PDA 빨리 막기 ↔ reverse PDA 막으면 24시간 내 사망 / 잡음 크기 ≠ 중증도
