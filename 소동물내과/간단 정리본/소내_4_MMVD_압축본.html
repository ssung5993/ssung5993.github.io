4. 승모판 질환 (MMVD) — 압축본 Myxomatous Mitral Valve Disease · 시험 직전용

원본 정리본(18p) 핵심만 압축 · ★ = 시험 강조 · 💡 = 원리 한 줄

판막 변성→MR→LA·LV 용적 과부하 (편심성)→LA압 → 폐수종 (PCW > 20–25)→보상 소진 + 부정맥 → 심근 부전

Ⅰ. 판막 기구 · 병리 · MR 원인

  • 승모판 기구: 큰 septal leaflet(중격 쪽) + 작은 mural leaflet / commissure / 유두근 2개가 각각 두 엽 모두에 건삭 / 건삭 1→3차로 갈라짐 / 판막륜
  • 💡 판막은 근육 ✕ — 압력차로 열리고 닫힘, 건삭(줄)+유두근 수축이 뒤집힘을 막음 → 어느 하나만 고장 나도 MR
  • 개 >> 고양이
  • 점액종성 변성 ★: 결절성으로 두꺼운 가장자리 · 콜라겐 변성 · 산성 뮤코다당 축적 → 건삭도 변성 → prolapse → MR
  • 💡 3층 중 spongiosa가 프로테오글리칸으로 부풀고 fibrosa 콜라겐이 끊김 → 두껍고 무거운데 약함 / 큰 septal leaflet이 더 잘 꺾임 → 편심성 제트
승모판 기구 — 낙하산(판막) + 줄(건삭) + 손(유두근)
MR의 원인 ★ — "MR은 질병이 아니라 현상"

💡 MR이 MR을 부름: LV 확장 → 판막륜 확장·유두근 벌어짐 → 기능성 MR이 덧붙어 역류↑ (되돌릴 수 없는 이유)

Ⅲ. 환자 · 증상 · 청진 · 중증도

  • Signalment: 순종, CKCS(6개월–1·2살에도), 노령, 소형견 / 동반질환: 치과, 기관허탈·기관지염, 관절 → 증상이 겹침(기침·운동불내성)

Ⅴ. 합병증 · 진행 · 바이오마커

  • 폐고혈압 원인 4: ① 만성 저산소 ② LA압↑(MMVD·MVD·IE·DCM) ③ 폐혈류↑(PDA·ASD·VSD) ④ 혈전색전(HW·PTE)
  • TR: same disease process, 단독으론 우심부전 드묾 / 폐고혈압 동반 시 우심부전 / sPAP = 4v² + RA압 → 예) 60 + 5 = 65 mmHg (개 정상 ~40까지)
  • 진행: 약은 늦출 뿐 못 막음 (mild → severe 4개월 예) / Severe MR → jet lesion → endocardial tear → LA 파열 → 심낭 출혈·tamponade → 돌연사(5 kg 소형견) / 건삭 파열 → 급성 MR
  • MMVD → MR → HF → myocardial failure (보상 소진 + 장기 부정맥, HR 160–200↑ 지속)
  • 예후: 진단 후 6개월–2년 / 개 1년 ≈ 사람 5년 → 치료 가치 설명
  • 바이오마커: NT-proBNP(늘어남·과부하) / cTnI(손상·괴사) → ① 심장성 vs 호흡기성 기침 감별 ② 진행 단계 ③ 치료 반응
