자극전도계 ★
  • 심방–심실은 절연(결합조직) → 전기는 오직 His로만 내려감 / AV junction = AV node + His ("nodal" ≈ "junctional")
  • AV node = 전기적 문지기: AN·N·NH 3구역, AN·N이 가장 느림, N은 재분극 후 불응기 → 💡 ① 심방 수축으로 심실 채울 시간(= PR) ② AF 때 일부만 통과시키는 필터
  • 좌각 = 얇은 전방 분지(고양이 HCM에서 차단 → 좌축편위) + 두꺼운 후방 분지
  • Purkinje 침투: 개·고양이·영장류 1/3 ↔ 말·소 전층(동시 흥분 → 벡터 상쇄 → 크기 평가 ✕, base-apex 유도)
  • WPW: His 외 우회로(지연 없음) → 짧은 PR + delta파 + 넓은 QRS, 회귀성 빈맥 회로 / ECG로만 진단

Ⅰ. 파형 ★

파형 = 전기적 사건
P심방 탈분극심방 재분극(Ta)은 QRS에 묻혀 안 보임
PR (= PQ)SA → AV node 대기 → HisPR 길면 AV node 문제 / 최근 수의 전문서는 PQ
QRS심실 탈분극Q(중격, 아래) → R(LV 압도, 위) → S(기저부, 아래)
T심실 재분극개는 양성·음성·이상성 모두 정상 가능
ST / QTST = 전체 탈분극 상태(기선)ST 하강·상승 = 허혈·비대·전해질 / QT는 HR 빠를수록 짧음
  • ★ R파는 항상 위: 이름 규칙 — R = 첫 위쪽 꺾임 / Q = R 앞 아래 / S = R 뒤 아래 / 위쪽 파가 없으면 QS → 아래로 깊은 파 = "뒤집힌 R"이 아니라 deep S
  • Supraventricular = AV node·His 절연면 위(SA·심방·AV node) → P 이상, QRS 정상(좁음) / 심실성 → QRS 넓고 기괴 (💡 His–Purkinje 고속도로를 타느냐)
  • 전기 ≠ 기계: 실제 수축은 QRS 뒤 / 승모판 도플러 E파 = 이완 초기 수동 유입, A파 = 심방 수축(= P의 기계적 결과)
  • P 흐린 서맥 → 아트로핀 후 P 사라짐 → 심초음파로 A파 확인 → P·A 모두 없으면 atrial standstill

  • 유도 = +극·−극 사이 전위. 높이 ≈ 벡터 × cos(각도) → 평행 = 최대 / 수직 = 평평 / 반대 = 최대 음성

  • Lead II가 표준: 심장 전기 흐름(SA → 심첨)과 축이 거의 같아 P·R 가장 큼

  • 개·고양이 right lateral 표준, 다리 겹치지 않게(합선) / 말·소는 base-apex

평균 전기축(MEA) 그리기

① 두 유도(예: I, III)의 QRS 순 진폭(위 − 아래) ② 각 축 위에 점 ③ 점에서 수직선 → 교점과 중심 = MEA. 예) I +4.5, III +22 → ≈ +81°(정상) / I +6, III +9 → ≈ +67°
