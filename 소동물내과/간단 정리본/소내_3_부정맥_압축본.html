원본 정리본(22p) 핵심만 압축 · ★ = 시험 강조 · 💡 = 원리 한 줄

  • 정의: 불규칙 / 너무 빠름 / 너무 느림 / SA node 이외에서 시작된 리듬
  • 유전성: Boxer(심근병증 → VT), Miniature Schnauzer(SSS, 중년 암컷), Cocker(SSS), German Shepherd / 후천성(多): DCM·HCM, MMVD 말기, 외상·감염성 심근염, 쇼크, K⁺ 이상, 독소루비신
  • 판막병(MMVD)은 주로 CHF로 사망(조절되면 2차 심근병 → 부정맥) ↔ 심근병은 부정맥 → 돌연사가 먼저, 조절되면 CHF
  • 기전 💡 ① 자동성 이상(손상 세포가 새치기) ② 촉발 활동(후탈분극 — 전해질·약물·카테콜아민) ③ 회귀(reentry): 고리를 계속 돎 — SVT·flutter·VT, 한 번 끊으면 멈춤(thump·제세동)

Ⅰ. Sinus 계열 · Atrial standstill

  • 이탈박동 = 긴 휴지 후 첫 박동 = 구조대 → 억제 ✕ / 속도로 판정: 40–60 junctional, 20–40 ventricular (예: 작은 칸 65개 @25 mm/s → 1500/65 ≈ 23 → 심실성)
  • 아트로핀 반응 검사 ★: 0.04 mg/kg SQ → 30분 후 ECG / ≥ 50% 증가 = 반응(vagal) / < 50% = SSS 가능성 (💡 브레이크 해제 vs 엔진 고장)
  • 실신: 뇌에 O₂·포도당 부족 — 심한 서맥·빈맥(💡 너무 빠르면 채울 시간 없음)·혈관 확장 / 저혈당은 발작이 더 흔함
  • 약 = SA node 빨리: propantheline(항콜린, D 1–2 mg/kg BID–TID) · terbutaline(β작용, D 1.25–5 mg/dog) · aminophylline(D 10–11 mg/kg TID–QID) → 실신 잦으면 pacemaker(경정맥 → RV 심첨, 스파이크 + 넓은 QRS)

Ⅱ. 조기박동 · 빈맥

  • 조기박동 = SA보다 먼저 이소성 발화 / 모든 빈맥은 조기박동에서 시작
  • Single · Couplet(2) · Run(3, 슬라이드 "2" 오타) · Tachycardia(≥3 지속) · Bigeminy(정상–비정상) · Trigeminy
  • Junctional PC: 💡 AV node에서 위·아래 동시 전파 → 음성 P가 QRS 앞·속·뒤
  • SVT vs sinus tachy = precordial thump ★: SVT는 잠시 정상으로 돌아왔다 재발(회귀 고리 끊김) / sinus tachy는 변화 없음
  • VPC: P 없음 + 넓고 기괴 + T 반대 방향 + 완전 보상 휴지(앞뒤 합 = R–R × 2) / RV 기원 = LBBB 모양, LV 기원 = RBBB 모양 / multiform = 더 위험
  • AIVR 80–120, ICU, benign → 💡 위험한 건 모양이 아니라 속도

Ⅲ. Flutter · AF · VF

★ AF 진단 = 3 + 1

① Supraventricular(QRS 좁음) ② Irregularly irregular ③ Usually fast → 기선에 P 없음(f파) 확인 (고양이도 동일)

  • 심방 400–700 → 심부전 개는 ~1/3만 AV 통과, 말은 1/8 / 💡 AV node가 불응기 끝난 순간 도착한 것만 통과 → 완전 불규칙
  • Flutter = 큰 회귀 1개 → 일정 톱니 / AF = 작은 파동 여러 개 → 무질서
  • AF 치료 = rhythm 아닌 rate (💡 LA가 이미 커서 곧 재발): digoxin으로 시작(미주신경↑ → AV 전도↓, 약한 수축력↑) → 저용량 diltiazem 또는 atenolol 추가 / 목표 ≤ 160 bpm
  • Cardioversion: 20 → 30 → 50 → 75 J, 100 J 넘지 않음, 마취 필수
  • VF: 약·제세동 반응 거의 없음 → VT 단계에서 잡아야 / 보호자에게 예후 미리 설명
★ 항부정맥제 — 홀수(Ⅰ·Ⅲ) = 심실성 / 짝수(Ⅱ·Ⅳ) = 심실상성
Class기전약물표적 / 💡

Ⅱβ-blockerEsmolol(IV), Atenolol, Carvedilol심실상성·속도 조절 — 결절의 교감 조절

Ⅳ. 방실차단 (AV block) ★

  • 1도: PR 김(개 정상 0.06–0.15 s), 모두 전도 = "not an arrhythmia"
  • Mobitz I (Wenckebach): PR 점점↑ → 탈락 → 짧은 PR로 재시작 (💡 AV node 피로) / 개에서 흔함
  • Mobitz II: PR 일정 → 예고 없이 탈락 → 더 걱정(His 이하, 진행 위험)
  • High grade: 2:1·3:1·4:1 — 연속 전도가 없어 I·II 구분 불가
  • 3도: complete AV dissociation → 심실 이탈 리듬: 넓고 20–40 = 심실성 / 좁고 40–60 = 접합부(nodal) / 캘리퍼로 P–P 찍으면 숨은 P 발견
  • 치료: 고등급 2도·3도는 약 효과 제한 · 아트로핀 무반응(💡 길이 끊겨서 P만 빨라짐) → pacemaker 적응증 = 실신, 차가운 사지, 혈중 젖산↑
*헷갈리기 쉬운 짝
  • SVT(thump 반응) ↔ sinus tachy(무반응) / AF(불규칙, P 없음) ↔ flutter(톱니 규칙) ↔ SVT(규칙)
  • VT ↔ AIVR(80–120, 치료 ✕) / VPC ↔ BBB(P·정상 PR 있음) / 이탈박동은 억제 ✕(리도카인 금지)
  • Mobitz I(PR 점점↑) ↔ II(PR 일정) ↔ high grade(구분 불가) ↔ 3도(완전 분리) / junctional 40–60 ↔ ventricular 20–40
