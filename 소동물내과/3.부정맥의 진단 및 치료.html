Ⅰ. 부정맥이란? 원인은?

1. 정의 (Arrhythmia Definition) 시험

Sinus rhythm이 아닌 모든 것

부정맥은 어떻게 생기나 — 기전 3가지
  • 자동성 이상(abnormal automaticity): SA node가 아닌 세포(손상·허혈·늘어난 심근)가 스스로 발화 속도가 빨라져 페이스메이커를 "새치기" → 조기박동·빈맥
  • 촉발 활동(triggered activity): 한 번 흥분한 직후 막전위가 다시 출렁여(후탈분극) 역치를 넘으면 추가 박동 — 전해질 이상·약물 독성·카테콜라민
  • 회귀(reentry): 전기 신호가 원을 그리며 계속 돎 — 길이 두 갈래이고 한쪽이 느리게 전도되면, 한 바퀴 돌아온 신호가 다시 흥분 가능한 조직을 만나 반복. SVT, atrial flutter, 허혈 부위 주변 VT의 주 기전 (슬라이드 VT 그림: "infarct 가장자리의 느린 전도 → 원형 회귀")
  • → 회귀성 빈맥은 회로를 한 번만 끊으면 멈춤 → precordial thump·전기 충격이 통하는 이유

1. 간단한 도구 — 캘리퍼(Caliper) 필기

  • R–R 간격 체크용. 한 R–R에 캘리퍼를 맞춘 뒤 다음 박동으로 그대로 옮겨 보면 → 간격이 같은지(regular) 한눈에 수업
  • 예상 위치보다 먼저 나온 박동 = 조기박동(premature)을 가장 쉽게 찾는 법 / 3도 방실차단에서 P파끼리 간격을 찍어 "P는 규칙적인데 QRS와 무관"을 확인할 때도 수업
그림 B. 캘리퍼 사용법 — R–R을 옮겨 보면 조기박동이 바로 보인다

2. 질문 1 — 심박수 시험

※ 가장 먼저 paper speed 체크, 그리고 sensitivity 체크

표준 세팅 = 50 mm/s, 10 mm/mV 필기 "스탠다드한 셋팅값" — 누군가 기록 중 값을 바꿨을 수 있으니 종이·이미지를 받으면 이것부터 수업

  • The longer you count, the more accurate you are — 기계도 오래 모니터해야 평균이 실제 값에 수렴 수업
  • R–R 사이 작은 칸 수로: 50 mm/s → 3000 ÷ 칸 (25칸 → 120 bpm) / 25 mm/s → 1500 ÷ 칸 (25칸 → 60 bpm) — 같은 25칸이어도 속도에 따라 2배 차이
  • Heart rate = 60 ÷ R–R(초): 슬라이드 예) R–R = 0.24 s → 60/0.24 = 250 bpm (빈맥) 필기 "60초일 때 몇 번 뛰는가?" (1 : 0.24 = X : 60)

3. 질문 2 — 규칙성

  • 캘리퍼로 R–R이 일정하면 regular, 아니면 irregular
  • 개: 숨을 들이쉬면 빨라지고 내쉬면 느려지는 호흡성 불규칙(sinus arrhythmia)이 정상적으로 흔함 수업
  • 고양이: 병원에선 호흡과 상관없이 R–R이 규칙적인 게 보통 → 고양이에서 "촘촘했다 늘어졌다"가 반복되면 특이 소견으로 봄 수업

1. Sinus rhythm · Sinus arrhythmia · Wandering pacemaker (정상 3총사)

Sinus rhythm — P·QRS·T 일정, R–R 일정
Sinus arrhythmia — 파형은 모두 정상, R–R만 호흡 따라 변함 ("흡기? 호기?")
흡기에 빨라지고 호기에 느려지는 이유 — 미주신경의 밀물·썰물
  • SA node엔 미주신경(부교감)이 브레이크처럼 붙어 있음. 흡기 때는 폐 신장 수용체·호흡중추 신호로 미주신경 활동이 억제 + 흉강 음압으로 정맥 환류↑ → 심박↑
  • 호기 때는 브레이크가 다시 걸림 → 심박↓
  • → 미주신경이 잘 작동한다는 건강한 신호라 개에선 정상. 휴식 중인 개, 단두종, 호흡기 질환에서 더 뚜렷. 흥분·스트레스(교감↑) 상태에선 사라짐 — 병원에서 고양이가 규칙적인 이유도 교감 긴장
  • 교수님 설명: 들이쉴 때 산소화된 혈류 공급이 늘며 빨라진다 수업
Wandering pacemaker — P 모양이 조금씩 변함 (높다 → 작다 → 음성 → 다시)
Wandering pacemaker는 왜 정상일까

SA node는 점 하나가 아니라 띠 모양 조직이고, 심방 안에도 예비 페이스메이커가 있음. 미주신경 긴장이 출렁이면 그때그때 가장 빠른 부위가 SA node 안팎·심방·AV node 근처로 옮겨 다님 → 출발점이 바뀌니 심방 탈분극 방향(=P파 모양)이 변함. 하지만 결국 심방→AV→His 정상 경로라 QRS는 그대로. sinus arrhythmia와 같은 "미주신경 리듬"의 친척 수업 "SA node가 건강하지 않고 근처·심방·AV 쪽에서 다양하게 페이싱"

  • No P waves seen or No P waves associated with QRS (P가 있어도 QRS와 무관)
  • 진행: VPC → VPC couplet → VPC run → VTachy

Ⅴ. Flutter(조동) & Fibrillation(세동)

1. Atrial flutter — 톱니(F파) 시험

Atrial flutter — 기선이 규칙적인 톱니, 심실 반응은 들쭉날쭉
  • Rare arrhythmia in any species (교수님 병원은 운 좋게 꽤 봄) 수업
  • Atrial rate 400–500 bpm (개) / Usually a variable ventricular response (irregular rhythm)
  • Saw teeth 필기 aka '톱니모양' 파형 — 캘리퍼로 F파 간격을 찍어 보면 아주 규칙적 수업
왜 flutter는 "규칙적인 톱니", fibrillation은 "무질서한 떨림"일까
  • Flutter = 심방 안을 도는 큰 회귀 회로 하나(macro-reentry) 수업 → 한 바퀴 도는 시간이 일정하니 F파가 일정 간격의 톱니. AV node는 그중 2개·3개·4개에 하나씩 통과시키니 심실 반응은 불규칙할 수 있음
  • Fibrillation = 수많은 작은 파동이 무작위로 돌아다님 → 심방 전체가 조직적으로 수축 못 하고 "떨기만" → 기선이 잔물결(f파), P 없음
그림 F. Flutter vs AF, 그리고 AV node가 심실 속도를 정하는 원리

2. Atrial fibrillation (AF) — 임상에서 가장 중요 시험

Atrial fibrillation — P 없음(f파), R–R 완전 불규칙, 빠름, QRS 좁음
14
  • Most common in small animals in dogs with severe cardiomyopathy — 특히 심한 DCM, LA가 크게 확장된 MMVD, 몸집 큰 개 수업
  • 심장이 클수록 AF가 비례해서 잘 생김 → 말·소는 정상 심장에서도 AF가 흔함 수업
  • 초음파상 심방이 수축하지 않고 흔들리기만 수업
  • Atrial rate 400–700 depolarizations/min / 심부전 개에선 그중 약 1/3만 AV node 통과 / 정상 심장의 말은 8개 중 1개만 통과
  • 예: 심실 200 bpm이면 심방에선 약 3배인 ~600회 전기 신호가 생겼을 것 수업
AF 진단 — Three primary characteristics + 1 시험
  1. Supraventricular — QRS 정상(좁음)
  2. Irregular (irregularly irregular) — R–R에 규칙성이 전혀 없음
  3. Usually fast — 심한 심장병이 같이 있으면 (빈맥)
  4. 위 3개를 만족하면 기선을 보고 P파가 없음을 확인 (f파는 있을 수 있음) → AF 진단 (고양이도 같은 방식)

f파가 촘촘해 안 보이면 paper speed를 바꿔 넓혀서 보기 수업

"불규칙하게 불규칙한(irregularly irregular)" 이유

심방에서 분당 수백 개의 무질서한 신호가 AV node에 쏟아짐. AV node는 불응기가 끝난 순간 마침 도착한 신호만 통과시키는데, 도착 타이밍이 무작위 → 통과도 무작위 → R–R에 아무 패턴이 없음. 또 심방 수축(atrial kick)이 사라져 심실 충만이 줄고, 빠른 심박으로 충만 시간까지 줄어 → 심박출량↓ → 심부전 악화.

"3초 마크 × 20" 예제 수업

종이 위 마크는 3초 간격 → 그 사이 QRS 6개 → 6 × 20 = 120 bpm. 소형견에서 120은 빈맥이라 보기 어렵지만, 대형·초대형견이면 판단이 달라짐 → 같은 숫자도 체격 기준으로 해석.

1) AF 치료 — 리듬이 아니라 "속도"를 잡는다

  • Usually cannot convert back to sinus rhythm → Treated with digoxin plus either diltiazem or β-blocker to slow ventricular rate
  • 목표: 심실 박동수를 개에서 160 bpm 이하로
  • 순서: digoxin으로 시작(미주신경 긴장↑) → 저용량 diltiazem 또는 저용량 β-blocker(atenolol) 추가 — 저용량에서 시작해 올리는 게 안전, 단독·병용 모두 가능
  • Cardioversion: 제세동기(전기 충격). 시작 에너지 20 J → 30 → 50 → 75 → 100 J를 넘지 않는다 — 100 J 넘으면 심장이 "타버림" / 작은 개는 100까지 가기 어려움 / 마취 필수(심장병 환자 마취라 어렵지만 전문 병원에선 가능) 수업
  • 빨리 뛰는 심장을 정상 속도로 돌리는 이식형 제세동기(페이스메이커와 비슷, 프로그램만 다름)도 있음 수업
왜 리듬 대신 속도 조절(rate control)인가 / digoxin의 원리
  • AF가 생길 정도면 LA가 이미 크게 늘어나 있음 → 정상 리듬으로 돌려도 늘어난 심방에서 곧 재발. 그래서 현실적 목표는 AV node를 덜 통과하게 해 심실 속도를 낮추는 것 → 충만 시간 확보 → 심박출량 회복
  • Digoxin: Na⁺/K⁺-ATPase 억제 → ① 약한 양성 수축력 ② 미주신경 긴장↑ → AV node 전도↓(좋은 음성 변시) → AF 심실 속도↓
  • Cardioversion: 심장 전체를 한 번에 탈분극시켜 모든 무질서한 파동을 "리셋" → 가장 빠른 SA node가 다시 주도권

3. Ventricular flutter · Ventricular fibrillation — "The Rhythms of Death" 시험

Ventricular fibrillation — 형태 없는 떨림 (coarse → fine)

그림 H. 방실차단 사다리 도식 — 심방 신호가 심실까지 내려가나?

1. 1도 방실차단 (First degree AV block) — "not an arrhythmia"

1도 AV block — PR이 일정하게 길고, 모든 P가 전도됨
  • 정상 PR 간격 (개) = 0.06–0.15초 시험
  • PR이 정상보다 길지만(교수님: 약 0.15–0.2초 사이) 모든 P가 QRS로 이어짐 → 엄밀히는 부정맥이 아님 수업 / 슬라이드 표기 "PR 간격이 0.2초 이하"

2. 2도 방실차단 (Second degree AV block)

1) Mobitz type I (Wenckebach)

Mobitz I — P는 규칙적, PR이 점점 길어지다 QRS 하나 탈락, 다시 짧은 PR로 시작
  • Progressive lengthening of PR interval with intermittent dropped beats — 길고, 더 길고, 더 길고 → P 다음 QRS가 빠짐 → 반복 수업
  • 개에서 흔한 형태 수업
18
Wenckebach의 원리 — AV node의 "피로"

슬라이드 그림 순서: 좋은 전도·정상 PR → 전도 덜 좋음·PR 김 → 더 나쁨·PR 더 김 → 전도 실패·QRS 탈락 → AV node 회복·PR 정상. AV node는 직전 흥분에서 완전히 회복하기 전에 다음 신호가 오면 점점 더 느리게 통과시키다, 결국 한 번 놓치며 쉬고 → 그 휴식으로 회복해 다시 짧은 PR로 시작. 미주신경 긴장이 높을 때 잘 생기고 AV node 안의 문제라 비교적 양성인 경우가 많음 (정리자 보충).

2) Mobitz type II

Mobitz II — PR이 일정한 채로 갑자기 QRS 탈락
  • PR 간격이 변하지 않고 일정하다가 예고 없이 QRS가 빠짐 — 교수님: 길어진 상태(0.2초 이상)를 그대로 유지 수업
Mobitz II가 더 걱정되는 이유

예고(점점 길어지는 PR) 없이 끊긴다는 건 문제가 AV node 아래(His–각) 쪽인 경우가 많다는 뜻 → 피로·회복 패턴 없이 갑자기 더 진행해 high grade·3도로 넘어갈 위험 (정리자 보충).

3) High grade second degree AV block

High grade (2:1) — P 2개당 QRS 1개
  • P:QRS = 2:1, 3:1, 4:1 — Mobitz I이 더 악화된 고등급 2도 / 2:1 → 3:1 → 4:1로 갈수록 나빠짐. 그래도 AV node가 최소한의 규칙성은 유지 수업
  • 정의(슬라이드): Mobitz I·II를 구분하려면 연속으로 전도된 심방 박동이 있어야 PR이 점점 길어지는지 볼 수 있음 → 연속 전도가 하나도 없으면 "High Grade"라고 부름
2:1이면 왜 type I인지 II인지 모를까

Type I과 II의 차이는 "연달아 전도된 박동들의 PR이 점점 길어지느냐, 일정하냐". 2:1에선 전도되는 박동이 항상 하나씩 떨어져 있어 비교할 연속 PR 쌍이 없음 → 판정 불가 → 따로 "high grade"로 묶음.

*헷갈리기 쉬운 짝
  • Sinus tachy vs SVT: 둘 다 좁고 빠르고 규칙 ↔ thump에 SVT만 잠시 정상화
  • Atrial flutter vs AF: F파 규칙적 톱니(400–500) ↔ f파 무질서, R–R 완전 불규칙(400–700)
  • VPC vs APC: 둘 다 일찍 ↔ VPC는 P 없음 + 넓고 기괴, APC는 P 다름 + QRS 정상
  • VPC vs BBB: 둘 다 넓은 QRS ↔ BBB는 P 정상 + 정상 PR
  • VT vs AIVR: 모양 같음 ↔ AIVR은 80–120, benign → 치료 X
  • 심실성 이탈박동 vs VPC: 넓은 QRS는 같음 ↔ 이탈박동은 긴 휴지 뒤 늦게(구조대 — 억제 금지), VPC는 일찍
  • Mobitz I vs II: PR 점점 길어지다 탈락 ↔ PR 일정한데 갑자기 탈락
  • High grade vs 3도: 2:1처럼 규칙적 비율로 전도 ↔ P와 QRS 완전 무관
  • Junctional vs ventricular escape: 좁음·40–60 ↔ 넓음·20–40
  • 아트로핀 반응: vagal 서맥은 반응(≥50%↑) ↔ SSS·3도 AVB는 무반응
  • Couplet vs Run: 2연속 ↔ 3연속 (슬라이드 "2개"는 오타)
  • 항부정맥제: 홀수 I(Na)·III(K) = 심실 ↔ 짝수 II(β)·IV(Ca) = 심실상
  • 판막병 vs 심근병 사망: MMVD는 주로 CHF ↔ DCM·HCM은 주로 부정맥 돌연사
✎ 원리 셀프체크 — 답을 가리고 설명해 보기
Q1. 50 mm/s 기록에서 R–R이 작은 칸 12개. 심박수와 판단은?
→ 12 × 0.02 = 0.24 s → 60/0.24 = 250 bpm, 빈맥 (3000/12 = 250).
Q2. 좁은 QRS, 220 bpm, 매우 규칙적. thump 후 잠깐 정상이 됐다가 다시 빨라짐. 진단은?
→ SVT (회귀 회로가 잠시 끊긴 것). sinus tachy면 thump에 변화 없음.
Q3. P가 안 보이고 R–R이 완전히 불규칙, QRS는 좁고 빠름. 다음 순서는?
→ AF. 치료 목표는 리듬이 아니라 심실 속도 ≤160 bpm: digoxin → 저용량 diltiazem/β-blocker.
Q4. ICU의 비장 수술 후 개, 넓은 QRS가 연속인데 105 bpm, 혈압 정상. 치료?
→ AIVR — benign, 혈역학 안정 → 약물 치료 안 함, 원인 관리·모니터링.
Q5. 긴 휴지 뒤 넓은 QRS 하나, 그 간격으로 계산하면 25 bpm. 리도카인을 줘야 하나?
→ 아니다. 심실성 이탈박동(구조대). 억제하면 위험. 원인(SSS·AV block) 쪽을 치료.
Q6. 서맥·sinus arrest인 코카, 아트로핀 후 60 → 130 bpm. 해석?
→ 50% 이상 증가 = 반응 있음 → 미주신경 과긴장(호흡기 질환 등) 가능성, SSS 가능성 낮음.
Q7. 요도 폐색 고양이, P파가 없고 T가 뾰족하며 서맥. 무엇이 문제이고 왜?
→ 고칼륨혈증에 의한 atrial standstill. K⁺ 배출로(소변)가 막혀 축적 → 가장 예민한 심방 근육부터 전도 소실.
Q8. P는 규칙적으로 150, QRS는 넓고 30 bpm, 둘이 따로 논다. 진단·치료?
→ 심실성 이탈 리듬을 동반한 3도 AVB. 아트로핀 무반응 → 실신·차가운 사지·젖산↑면 pacemaker.
Q9. 2:1 전도인 AV block을 Mobitz I/II로 분류할 수 없는 이유는?
→ 연속으로 전도된 박동이 없어 PR 변화를 비교할 수 없음 → "high grade"로 분류.
Q10. 왜 diltiazem·β-blocker는 심실상성, lidocaine·sotalol은 심실성 빈맥에 주로 쓰나?
→ SA·AV node는 Ca²⁺ 통로·교감 조절로 작동(II·IV가 표적) / 심실 근육은 Na⁺·K⁺ 통로로 작동(I·III가 표적).
