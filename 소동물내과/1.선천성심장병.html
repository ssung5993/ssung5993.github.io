3. 진단의 첫 단추 = 청진 수업

  • 어린 개체에서 잡음(murmur)이 들린다 → 선천성 심장병을 거의(90% 이상) 의심 — "100%는 아니지만"
  • 청진은 "작은 툴 하나"지만 태어날 때부터 가진 병을 조기 발견할 수 있는 거의 유일한 도구 → 어린 강아지·고양이는 정기적으로 부지런히 청진
  • 청진으로 대략 어떤 질환인지 플로차트를 그리고 → 흉부방사선 · 심전도 · 혈압 · 심장초음파(확진) · 혈관조영 순으로 좁혀감

1) Innocent murmur (순수잡음) — 병이 아닌 잡음

  • 대개 soft systolic ejection-type / left heart base에서 가장 잘 들림
  • 약 4개월령(16주)까지 사라짐 → 그 이후에도 들리면 병적 잡음 의심 시험
왜 어린 동물은 병이 없어도 잡음이 들릴까? 원리
  • 잡음 = 혈류가 난류(turbulence)가 되면서 나는 소리. 난류는 속도↑, 혈관 직경↑, 점도↓일수록 잘 생김
  • 어린 동물은 ① 심박출량이 커서 혈류 속도가 빠르고 ② 아직 PCV가 낮아 혈액 점도가 낮고 ③ 흉벽이 얇아 소리가 잘 전달됨 → 정상 판막을 지나는 피도 살짝 난류 → 부드러운 박출성 잡음
  • 자라면서 이 조건이 사라지니 4개월쯤 소실. 같은 원리로 빈혈·발열(점도↓·속도↑)에서도 physiologic murmur가 생김

4. 수정 베르누이 공식 — 속도로 압력을 잰다 시험

*왜 속도로 압력을 알 수 있나?
좁은 곳을 지나려면 피가 빨라져야 함 → 그 가속에 쓰인 에너지 = 양쪽의 압력 차이. 그래서 협착이 심할수록(압력차↑) 제트 속도↑. 도플러는 속도만 재지만 공식으로 압력차로 환산.

ΔP (mmHg) = 4 × v²  (v = 최고 유속, m/s)

  • 5 m/s → 4×25 = 100 mmHg 수업 — 교수님이 PS·VSD·PDA에서 반복 계산
  • PS 예시 영상: 5 m/s ≈ 100 mmHg → > 80이므로 severe
  • VSD 정상 LV–RV 차 ≈ 100 mmHg ↔ 4.5–5 m/s
  • PDA 예시 영상: 6.44 m/s → 4×6.44² ≈ 166 mmHg — 대동맥·폐동맥 압력차가 크게 유지됨 = 폐고혈압 없음

Ⅲ. Extra-Cardiac Shunt — 동맥관개존증 (PDA) Patent Ductus Arteriosus

1. 병인 — 왜 안 닫히나

  • 정상: 동맥관은 출생 후 수 시간 내 수축 → 이후 수 주에 걸쳐 영구 폐쇄 수업 "쪼그라들면서 서서히 완전히 닫혀야"
  • PDA: 동맥관 벽이 비정상 — 평활근은 적고 탄력섬유(elastic fiber) 비율이 높음 → 효과적으로 수축하지 못함 → PDA 시험
"탄력섬유가 많다"가 왜 문제?

동맥관을 닫는 힘은 평활근의 능동적 수축(산소↑·PGE₂↓에 반응)이다. 탄력섬유는 늘어났다 돌아오는 수동적 조직이라 신호를 받아도 오그라들지 못함 → 벽 구조가 대동맥 벽을 닮아 "열린 혈관"으로 남는다.

3. 임상적 특징 (좌→우 단락)

  • 운동능력 저하, 빈호흡(tachypnea), 기침 — 하지만 처음 진단 시 많은 동물이 무증상 (진료 시점에 따라 유증상/무증상)
  • 연속성 잡음(continuous murmur), left base에서 최대 — 흔히 precordial thrill(흉벽 떨림) 동반 / 가끔 수축기 잡음만
  • Hyperkinetic (bounding, "waterhammer") 동맥맥 — 대퇴동맥 촉진 시 강하게 튀는 맥 시험
왜 맥이 "튀는(bounding)" 느낌일까 — 맥압(pulse pressure) 원리
  • 수축기: LV가 (폐에서 돌아온 여분의 피까지) 많은 양을 박출 → 수축기압↑
  • 이완기: 대동맥판은 닫혔는데 피가 동맥관을 통해 압력 낮은 PA로 계속 빠져나감(diastolic run-off) → 이완기압이 뚝 떨어짐 수업
  • → 맥압(수축기−이완기) 폭이 커짐 = 손끝에 확 올라왔다 확 꺼지는 맥

  • 큰 ASD → 우심 CHF 증상

1) 신체검사

  • 운동 제한 / 풍선 판막성형술 — PS 교정용 (VSD는 대동맥 근처라 시술로 막기 어려움) 수업
왜 "전신 동맥 → 폐동맥" 연결이 도움이 되나

TOF의 문제는 폐로 가는 피가 부족한 것. 압력 높은 전신 동맥 피 일부를 폐동맥으로 돌리면 = 인공 PDA를 만드는 셈 → 폐혈류↑ → 산소화된 피↑ → 청색증 완화.

Q1. PDA인데 RV는 왜 정상 크기일까?
→ 새는 피의 고리(Ao→PA→폐→LA→LV→Ao)에 RV가 없음. 과부하는 PA 이후~LV.
Q2. PDA 환자에서 연속성 잡음이 수축기 잡음만으로 바뀌었다. 무슨 뜻?
→ 폐동맥압↑로 이완기 Ao–PA 압력차 소실 → 폐고혈압 진행, reverse PDA로 가는 중일 수 있음.
Q3. Reverse PDA 개에서 입 점막은 분홍인데 생식기 점막이 청색인 이유?
→ 동맥관이 머리·앞다리 분지 이후의 하행대동맥에 붙어 있어 정맥혈이 미측으로만 감 (차등 청색증).
Q4. SAS 개가 놀다가 실신·돌연사하는 기전 2가지는?
→ ① LV 비대 + 관류↓ → 심내막하 허혈·섬유화 → 심실성 부정맥 ② 운동 시 박출 못 늘림 + 반사성 서맥·저혈압.
Q5. VSD 스펙트럴 도플러 단락 속도가 2 m/s로 낮다. 좋은 소식?
→ 아님. 4×2² = 16 mmHg로 LV–RV 압력차가 작다 = RV 압력↑(PS 또는 폐고혈압) 의심.
Q6. ASD에서 PS가 없는데 left base 박출성 잡음이 들린다. 왜?
→ 단락으로 늘어난 피가 정상 폐동맥판을 지나며 난류 = 상대적(기능적) PS.
Q7. PS 심초음파 단축상에서 LV가 D자 모양. 왜?
→ RV 압력이 LV에 근접·초과 → 중격이 LV 쪽으로 밀려 편평.
Q8. TOF 개는 쉴 땐 분홍, 운동하면 청색. 왜?
→ 운동 시 SVR↓ → RV 피가 VSD→대동맥으로 더 감(우→좌↑) + 누두부 조임↑.
Q9. TOF에서 PCV 78% → 왜 45%가 아니라 60–65%까지만 사혈?
→ 적혈구증가증은 저산소 보상. 과점도만 해소할 정도로 낮춰야 산소 운반 유지.
